## PDCA三级循环

| 循环 | 周期 | 核心产出 |
|------|------|---------|
| PDCA-A | 月度 | 预警闭环率 + 超期预警清单 + 改进行动 |
| PDCA-B | 季度 | 3GAP分析 + 3List行动清单 + 调拨建议 |
| PDCA-C | 年度 | 组合校准 + 下年建议 + 数据归档 |

---

## 3GAP分析维度

- GAP1 目标差距：年度目标 - 当前预测 → 对应必赢行动
- GAP2 执行差距：当前预测 - 实际完成 → 对应改善行动
- GAP3 预测变动：本期预测 - 上期预测 → 对应资源调整

---

## 3List分类

| 清单 | 触发条件 | 处置方向 |
|------|---------|---------|
| 必赢清单 | GAP1大且战略优先级高 | 高效执行，优先配置资源 |
| 改善清单 | GAP2大但可通过管理优化 | 流程改进，成本优化 |
| 资源清单 | GAP3大需补充资源 | 人员招聘，预算追加评估 |

## KPI计算公式与实例

### 全局执行率
```
执行率 = Σ已核销金额 / Σ年度预算金额 × 100%
       = 211,484,000 / 389,700,000 × 100%
       = 54.3%
```

### 象限执行率
```
象限执行率 = Σ象限已核销 / Σ象限年度预算 × 100%
发展象限   = 51,040,000 / 90,000,000 × 100% = 56.7%
探索象限   = 18,900,000 / 64,000,000 × 100% = 29.5%
```

### 闭环率
```
闭环率 = 已闭环预警数 / 预警总数 × 100%
       = 6 / 25 × 100% = 24.0%（未达标，目标≥80%）
```

### 超期天数计算
```
超期天数 = 当前日期 - 响应截止日期
AL-2026-0503: 截止 2026-06-04，当前 2026-06-05 → 超1天 → 红色升级
```

### L1科目执行率
```
B2研发支出执行率 = ΣB2下所有项目已核销 / ΣB2下所有项目年度预算 × 100%
B2已核销 = 904万(B2.01) + 780万(B2.02) + 210万(B2.03) + 120万(B2.04)
         = 20,140,000
B2年度预算 = 2,000万 + 1,500万 + 600万 + 800万 = 4,900万
B2执行率 = 2,014万 / 4,900万 × 100% = 41.1%
```

### 预警偏差率
```
偏差率 = (触发值 - 阈值) / 阈值 × 100%
AL-2026-0502: 触发值780万 vs 阈值600万 → (780-600)/600 × 100% = +30.0%
              → 偏差率+30% → 触发"执行率严重超阈值"红色预警
```

### 调拨可行性判断
```
调入项目可用余额 ≥ 申请调拨金额 → 可批准
TF-2026-005: BGT-2026-B7-002可用余额72万，申请500万 → 不足，拒绝或分期
```

### 现金流指标
- 经营性现金流执行率 = 实际经营性现金流 / 预算经营性现金流 × 100%
- 现金执行率 = 实际现金支出 / 预算现金支出 × 100%
- 现金流偏差 = 预算执行率 - 现金执行率（正常范围≤5%）

### 研发效能指标
- 管线NPV（风险调整后净现值）= Σ(各阶段成功概率 × 阶段现金流) / (1+WACC)^t
- 研发投入资本化率 = 资本化研发支出 / 总研发支出 × 100%（参考：III期临床后可资本化）
- 临床推进速度 = 实际入组人数 / 计划入组人数 × 100%

### 人效指标
- 人均预算执行额 = 已核销金额 / 部门人数
- 人均创收 = 部门收入 / 部门人数
- 预算人员效率 = 实际执行额 / 编制人数预算定额

## 指标间逻辑校验规则

### 执行率与象限一致性校验
- 发展象限执行率 < 60% → 必须触发红色预警
- 收缩象限执行率 > 70% → 必须触发红色预警
- 稳定象限执行率偏离目标 > 20% → 必须触发红色预警
- 探索象限执行率 < 20% 或 > 70% → 必须触发橙色预警

### 闭环率与预警等级联动
- 闭环率 < 80% → 月度PDCA-A必须列入改进行动
- 闭环率 < 60% → 升级至PDCA-B季度复盘

### 偏差率与灯色映射
- 偏差率 ±10%以内 → 绿色
- 偏差率 -10%~-20% → 蓝色
- 偏差率 -20%~-30% → 黄色
- 偏差率 -30%~-50% → 橙色
- 偏差率 <-50%或单项偏差>阈值 → 红色

### 现金流偏差校验
- 现金流偏差 > 5% → 触发蓝色预警，提示"预算执行率与现金执行率偏离过大"

### L1科目执行率与预警联动
- L1科目执行率低于象限目标20%以上 → 触发橙色预警
- L1科目执行率低于象限目标30%以上 → 触发红色预警

### 超期天数升级规则
- 超期1天 → 红色预警自动升级管理层
- 橙色预警3次合并 → 升级红色
- 黄色/蓝色预警 → 月度复盘关注/升级
