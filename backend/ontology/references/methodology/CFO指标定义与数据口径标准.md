# 方法论：CFO指标定义与数据口径标准

---

## 1. 核心原则

**每一个指标必须有明确的口径、来源和计算公式。CFO 不接受模糊定义。**

指标失准 → 预警误判 → 决策失误，整个链路不可断裂。

---

## 2. 执行率（核心指标）

### 2.1 标准口径

```
执行率 = Σ 已核销金额 / Σ 年度预算 × 100%
```

### 2.2 分母规则

- 仅计算 **已授予 + 执行中** 状态的预算项目
- 冻结金额不计入分母（冻结≠已使用）
- A 类和 B 类分开统计，不混用

### 2.3 分子规则

-分子为**实际核销金额**（非审批中金额）
- 按费用发生日期归口，非报销提交日期
- 跨年费用计入费用发生年度

### 2.4 象限执行率

```
象限执行率 = Σ 该象限已核销金额 / Σ 该象限年度预算 × 100%
```

| 象限 | 预期执行率 | 说明 |
|------|-----------|------|
| 发展 | ≥80% | 战略优先方向，应全力保障执行 |
| 收缩 | ≤50% | 该压降的方向，执行率过高是危险信号 |
| 稳定 | 60%±10% | 正常区间，超出需关注 |
| 探索 | 50%±20% | 不确定性高，弹性执行 |

---

## 3. 闭环率

### 3.1 标准口径

```
闭环率 = 已闭环预警数 / 全部预警数 × 100%
```

### 3.2 闭环判定标准

预警闭环须同时满足：
1. **业务响应**：责任人已在系统中确认处理措施
2. **财经BP确认**：财务BP验证闭环措施有效性
3. **双签归档**：系统记录归档

### 3.3 阈值标准

| 闭环率 | 评级 | 行动 |
|--------|------|------|
| ≥95% | 优秀 | 保持，纳入KPI基准 |
| 80–95% | 良好 | 持续监控 |
| <80% | 需改进 | 触发专项整改建议 |

---

## 4. 灯色评分规则

### 4.1 灯色定义

| 灯色 | 含义 | 执行率偏差 | 响应时效 |
|------|------|-----------|---------|
| 绿色 | 健康 | ±10%以内 | 例行关注 |
| 蓝色 | 关注 | -10%~-20% | 72小时 |
| 黄色 | 预警 | -20%~-30% | 48小时 |
| 橙色 | 严重 | -30%~-50% | 24小时 |
| 红色 | 危险 | <-50%或单项偏差>阈值 | 即时 |

### 4.2 综合评分公式

```
灯色评分 = (红色×4 + 橙色×3 + 黄色×2 + 蓝色×1) / 总预警数
```

评分 > 3.0 → 综合灯色偏红，需战略层关注

## 5. 3GAP 分析法

| GAP | 定义 | 计算方式 | 对应行动 |
|-----|------|---------|---------|
| **GAP1：目标差距** | 年度目标 - 当前预测 | 年度目标 - 当前预测 | 对应必赢行动 |
| **GAP2：执行差距** | 当前预测 - 实际完成 | 当前预测 - 实际完成 | 对应改善行动 |
| **GAP3：预测变动** | 本期预测 - 上期预测 | 本期预测 - 上期预测 | 对应资源调整 |

---

## 6. 3List 分类法

| 清单 | 性质 | CFO 行动导向 |
|------|------|-------------|
| **List1：必赢清单** | 已确定要发生的项目/费用 | 抓执行，重效率 |
| **List2：改善清单** | 存在不确定性或潜在风险的事项 | 看隐患，清风险 |
| **List3：资源清单** | 尚未纳入规划的新市场/新机会 | 找机会，评估是否值得追加投入 |

---

## 7. B→A 转换规则

| 阶段 | 条件 | 系统动作 |
|------|------|---------|
| B类授予 | 年初授予预估额度的50-70% | 额度部分冻结 |
| 季度检视 | 效果达标 → 批准转换 | 全额锁定 |
| 季度检视 | 效果未达预期 | 冻结剩余额度 |
| B→A转换后 | 全额锁定，可执行报销 | 解冻额度 |

## 8. 象限组合失衡判定

当象限分布偏离以下比例时，触发组合失衡告警：

|象限|参考下限|参考上限|
|---|---|---|
|发展|≥25%|≤50%|
|收缩|≤10%|≥25%|
|稳定|≥20%|≤40%|
|探索|≤10%|≤25%|

## 9. 现金流指标口径（华为实践）

华为财经管理核心是"利润+现金流双轮驱动"。

- **经营性现金流执行率** = 实际经营性现金流 / 预算经营性现金流 × 100%
  - 分子：经营活动产生的现金流量净额（按月度累计）
  - 分母：年度预算中经营活动现金流量净额（按时间进度折算）
  - 正常范围：80%-120%

- **现金执行率** = 实际现金支出 / 预算现金支出 × 100%
  - 分子：实际已支付的现金总额
  - 分母：预算中应支付的现金总额
  - 与预算执行率的偏差正常范围：≤5%

- **现金流偏差** = 预算执行率 - 现金执行率
  - >5%：存在预算已核销但现金未支付的情况（可能存在应付账款积压）
  - <-5%：存在现金已支付但预算未核销的情况（可能存在预付款过多）

## 10. 研发效能指标口径（药企实践）

- **管线NPV（风险调整后净现值）** = Σ(各阶段成功概率 × 阶段现金流) / (1+WACC)^t
  - 各阶段成功概率参考：临床前→I期 10%、I期→II期 25%、II期→III期 50%、III期→NDA 85%、NDA→商业化 95%
  - WACC参考：药企通常8%-12%

- **研发投入资本化率** = 资本化研发支出 / 总研发支出 × 100%
  - 资本化条件：III期临床后，满足技术可行+有完成意图+有能力完成+将来能产生经济利益
  - 行业参考：创新药企通常20%-40%

- **临床推进速度** = 实际入组人数 / 计划入组人数 × 100%
  - 按月度跟踪，<80%触发预警
  - 影响因素：中心启动速度、受试者筛选率、脱落率

## 11. 人效指标口径（华为实践）

华为强调"人效是核心经营指标"。

- **人均预算执行额** = 已核销金额 / 部门人数
  - 用途：衡量部门预算执行效率
  - 对标：与同规模企业同部门对比

- **人均创收** = 部门收入 / 部门人数
  - 用途：衡量部门人均产出
  - 对标：与行业标杆对比

- **预算人员效率** = 实际执行额 / 编制人数预算定额
  - >100%：人员效率高于预期
  - <80%：可能存在人员冗余或执行不力

## 12. 指标间逻辑校验规则

华为数据治理强调"指标间逻辑自洽"：

1. **执行率+闭环率+灯色评分一致性校验**：
   - 执行率>90% + 闭环率>95% → 应为绿色，若非则数据异常
   - 执行率<70% + 闭环率<80% → 应为橙色或红色，若非则阈值设置异常

2. **预算执行率≈现金执行率**：
   - 偏差≤5%：正常
   - 偏差5%-10%：关注，需核实应付/预付账款
   - 偏差>10%：预警，可能存在数据质量问题

3. **3GAP逻辑校验**：
   - GAP1 + GAP2 应能解释执行率偏差的主要原因
   - GAP3 累计值应与滚动预测调整幅度一致
