# 方法论：CFO交互标准与沟通范式

---

## 1. 核心原则

**理解 CFO 的决策场景，再给结论。**

CFO 的时间是战略资源，不是操作层面的客服。每一个回答，都必须想清楚：CFO 接下来要做什么决策？

---

## 2. CFO 决策场景分类

### 2.1 战略评估场景

**触发条件**：CFO 关注资源配置方向、象限组合、重大调拨
**典型问法**：
- "这个方向还要不要继续投？"
- "预算组合是否需要调整？"
- "发展象限是不是投太多了？"

**沟通原则**：
- 先结论，后数据
- 结论须有战略方向支撑（不是单纯财务指标）
- 主动提示调拨选项和审批路径

### 2.2 经营监控场景

**触发条件**：CFO 查看日常经营数据、月度快报、预警汇总
**典型问法**：
- "当前执行率是多少？"
- "本月有什么预警？"
- "闭环率达标了吗？"

**沟通原则**：
- 数字 + 灯色 + 趋势，三件套并行
- 异常数据主动标红，不需要 CFO 追问
- 提供下钻入口，但不主动跳转

### 2.3 复盘诊断场景

**触发条件**：CFO 主持月度经营分析会 / 季度复盘会
**典型问法**：
- "本期为什么出现偏差？"
- "GAP1 是多少？"
- "下期有什么改进行动？"

**沟通原则**：
- 结论先行（先说 GAP，再说原因，最后行动）
- 提供3GAP + 3List 结构化输出
- 改进行动须带责任人和时间节点

## 3. 回答范式

### 3.1 战略层问题回答模板

```
结论：{是/否需要调整资源配置，方向是什么}
数据支撑：
  - 象限A执行率：X%（目标≥80%）
  - 象限B执行率：Y%（目标≤50%）
  - 组合评价：{均衡/失衡}
调拨建议：
  - 从 {源象限} 调拨 {金额} 至 {目标象限}
  - 审批路径：{财经中心审批/管委会审批}
风险提示：{如有}
```

### 3.2 经营层问题回答模板

```
核心指标：执行率 X% | 灯色 {红X/橙X/黄X} | 闭环率 Y%
关键异常：
  -🔴 {预警ID}：{问题描述}，责任人：{姓名}
下期关注：
  - {象限/科目} 执行率偏低，需 {动作}
下钻入口：{技能跳转建议}
```

### 3.3 复盘场景回答模板

```
3GAP分析：
  - GAP1（目标差距）：{X}%
  - GAP2（执行差距）：{Y}%
  - GAP3（预测变动）：{Z}%
3List行动清单：
  - 必赢清单：{N}项，重点关注 {列表}
  - 改善清单：{M}项，风险点 {列表}
  - 资源清单：{K}项，机会点 {列表}
改进行动建议：
  1. {行动描述} → 责任人：{角色} → 时间：{节点}
  2. ...
```

### 华为汇报范式

华为汇报强调"3分钟说清楚"，采用结论先行、分层展开的方式：

**电梯演讲式（30秒摘要+3分钟核心+详细展开）**：
1. **30秒摘要**：一句话结论 + 三个关键数据 + 一个核心建议
2. **3分钟核心**：问题定位 + 根因分析 + 行动方案
3. **详细展开**：数据支撑 + 方案细节 + 风险评估

**结论先行原则**：
- 先给结论/判断，再给数据支撑
- 先给建议/方案，再给分析过程
- 先给风险/机会，再给详细说明

### 多受众适配

华为沟通强调"因人施策"，不同受众需要不同的表达方式：

| 受众 | 核心需求 | 表达方式 | 详细程度 |
|------|---------|---------|---------|
| CFO | 数据+判断+建议 | 结构化呈现，结论先行 | 中等，聚焦决策相关 |
| 管委会 | 议题+方案+风险+资源需求 | 议案式，含审批请求 | 精简，聚焦审批事项 |
| 董事会 | 摘要+关键指标+战略影响 | 高管摘要版，趋势图为主 | 概要，聚焦战略层面 |
| 业务部门 | 问题+操作指引+支持需求 | 操作指南式，步骤清晰 | 详细，聚焦可操作 |

## 4. 主动披露规则

发现以下情况时，无需等待追问，主动披露：

| 情况 | 主动提示内容 |
|------|------------|
| 数据缺失 | "⚠️ {月份}数据待确认，结论以此为基准" |
| 象限失衡 | "⚠️ {象限}执行率偏离参考范围，建议评估" |
| 闭环率异常 | "⚠️ 闭环率{X}%< 80%，建议启动整改" |
| 超期预警 | "⚠️存在{X}条超期预警未闭环，需优先处理" |
| B→A异常 | "⚠️ {项目} B→A转换冻结，需跟进原因" |

### 异常升级沟通范式

华为危机管理强调"第一时间上报"：

**系统性风险升级沟通**：
1. **即时报告**：发现后1小时内上报CFO
2. **初步判断**：说明风险等级、影响范围、可能后果
3. **建议方案**：提供2-3个应对方案及利弊分析
4. **资源需求**：明确需要协调的资源和授权

**合规风险升级沟通**：
1. **即时报告**：发现后立即报告CFO+合规负责人
2. **暂停操作**：暂停相关业务操作，防止风险扩大
3. **启动调查**：联合合规部门启动调查
4. **定期更新**：每24小时更新一次调查进展

---

## 5. 禁止事项

- ❌ 不确认决策场景就输出数据
- ❌ 用经营层数据回答战略层问题
- ❌ 隐瞒数据异常，等 CFO 追问
- ❌ 在复盘场景只给数字不给原因分析
- ❌ 输出未经核验的数据
