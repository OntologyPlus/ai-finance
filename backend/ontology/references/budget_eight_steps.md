# 预算全生命周期管理参考

---

## 预算管理的本质：战略到执行的价值传导链

>预算不是财务行为，是战略行为。每一笔预算的增减，背后都应该是战略意志的体现。

**战略牵引的核心逻辑：从上往下，先定方向，再配资源。**

```
SP（战略规划）
  ↓
年度预算组合（钱往哪倾斜）
  ↓
业务执行（具体怎么花）
  ↓
八步贯通（预算→报销→预警→复盘→报表→次年预算）
```

---

## DSTE战略解码链路（华为实践）

华为DSTE（Develop Strategy To Execution）是从战略到执行的核心流程，确保"战略可落地、过程可管控、结果可衡量"。

**三次战略解码**：
1. 第一次：SP阶段战略解码——通过BLM模型，将战略规划解码为关键任务（3-5年）
2. 第二次：BP阶段战略解码——将战略解码为年度业务计划，配好资源（1年）
3. 第三次：部门层面战略解码——将组织战略解码为岗位PBC（个人绩效承诺）

**BEM战略解码六步法**：
1. 明确战略方向及其运营定义
2. 导出CSF（关键成功因素）
3. 导出战略KPI
4. 确定年度重点工作
5. 制定PBC（个人绩效承诺）
6. 闭环管理

**SP→预算映射链路**：
战略意图 → BEM解码 → CSF → KPI → 年度预算项 → 季度里程碑 → 月度执行监控

## A/B类预算差异化管理

| 维度 | A类（战略专项） | B类（前置探索） |
|------|--------------|--------------|
| **本质** | 目标明确、计划确定、用项目管理方式管 | 有不确定性，接近发生才确定，重点监控异常膨胀 |
| **授予方式** | 立项即全额授予，额度锁定，执行中不做弹性调整 | 年初授予预估额度的50-70%，按季度里程碑验证效果后分批释放 |
| **报销挂账** | 挂项目预算ID | 挂暂存项目预算ID（B→A转换后正式关联） |
| **不确定性** | 低 | 高 |
| **转换机制** | 不需要转换 | 效果达标 → B→A转换全额锁定；效果未达预期 → 冻结剩余额度 |

## 战略意图维度

**第一层：三大战略方向**

| 战略方向 | 核心含义 | 预算导向 |
|---------|---------|---------|
| **全渠道商业化** | 直接创造收入的领域 | 资源配置优先保障，与收入增长联动 |
| **创新研发** | 支撑未来收入的研发投入 | 长期布局，阶段性评审，不以短期ROI为唯一衡量 |
| **国际化** | 支撑全球化布局和国际化扩张 | 战略卡位，优先投入已准入市场，新兴市场设上限 |

**第二层：产品线 × 区域**

```
战略意图维度
  ├── 第一层：三大战略方向（全渠道商业化 / 创新研发 / 国际化）
  │       ↓
  └── 第二层：产品线（大区/省区/地区）
          └── 管线阶段维度：临床前/I期/II期/III期/NDA/商业化
```

## 四象限预算组合

| 象限 | 战略含义 | 预期执行率 | 管控原则 |
|------|---------|-----------|---------|
| **发展** | 战略优先方向，全力保障 | ≥80% | 应投尽投，优先释放额度 |
| **收缩** | 该压降的方向 | ≤50% | 执行率过高是危险信号，触发预警 |
| **稳定** | 成熟业务，维持性投入 | 60%±10% | 正常区间，超出需关注 |
| **探索** | 不确定性高，试点探索 | 50%±20% | 设上限，弹性执行 |

## 预算制订三结合原则

| 原则 | 说明 |
|------|------|
| **自上而下** | 管委会下达战略框架和目标约束 |
| **自下而上** | 各中心和业务单元基于一线实际情况进行申报 |
| **上下结合** | 财经中心汇总、PK、平衡，最终经过管委会审批，形成年度预算 |

**两结合失败的后果**：

| 单独使用自上而下 | 单独使用自下而上 |
|----------------|----------------|
| 脱离一线实际，执行意愿低 | 业务倾向于多报需求，资源总量失控 |
| 战略框架无法落地 | 只反映现有业务惯性，不反映战略意图 |

### 1. 战略结合
- 预算须体现年度战略方向
- 发展象限占比须≥年度总预算的20%
- 探索象限占比须≤年度总预算的15%

### 2. 业务结合
- 预算须与业务计划匹配（销售计划/研发管线/市场活动）
- 销售激励预算须与销售目标联动
- 研发预算须与临床进度节点联动

### 3. 资源结合
- 人力成本预算须与人员编制计划匹配
- 中心间共享资源须提前协调
- 跨期项目须在预算说明中明确分年计划

## 零基预算(ZBB)方法论（华为实践）

华为预算编制强调"每年从零开始，不搞基数+增长"。零基预算的核心是三问：
1. **为什么要做？** —— 必须关联战略意图或合规要求
2. **为什么要花这么多？** —— 必须提供成本构成明细和行业对标
3. **为什么是现在？** —— 必须说明时间紧迫性和机会成本

ZBB实施步骤：
1. 决策单元划分：按战略举措/项目/科目划分预算单元
2. 决策包编制：每个单元独立编制"决策包"（含目的、方案、成本、效益）
3. 排序与取舍：按战略优先级排序，资源有限时从低优先级开始削减
4. 汇总与审批：自下而上汇总，自上而下平衡

## B→A转换管理

### 转换条件
```
必要条件（全部满足）：
 ① B类项目预算状态=执行中或已授予
  ② 里程碑验收完成（里程碑status=已完成）
  ③ 项目已达到预期效果（通过CFO/CFO-BP确认）

充分条件（满足任一）：
 ① 里程碑达成且效果达标 → 立即转换
 ② 里程碑达成但效果待验证 → 观察1个月后转换
 ③ 观察期后效果仍不达标 → 冻结剩余额度，不转换
```

### 转换操作流程
```
Step 1: 里程碑验收
 责任人提交里程碑完成证明 → 填写completed_date和notes
  → Finance BP确认验收结果

Step 2: 效果评估
  CFO/CFO-BP评估项目效果 → 确认是否满足转换条件
  → 确认转换时间（立即 or 观察期后）

Step 3: 系统操作
  在 b2a_conversions 表中：
  - 更新 conversion_date = T()
  - 更新 b2a_status = "已完成"
  - 更新 milestone_met = 1

Step 4: 预算额度锁定
  将暂存预算ID替换为正式项目预算ID
  解冻剩余额度，纳入正式预算管理

Step 5: 归档记录
  在 b2a_conversions.notes 中记录转换结论
  纳入PDCA闭环记录
```

### B→A 转换示例
```
BGT-2026-B2-001（创新药III期临床）
  里程碑：III期临床首例入组完成
  验收时间：2026-03-28
  效果评估：通过 → CFO确认
  转换日期：2026-03-28
  b2a_status: 已完成
  备注：里程碑达成B→A完成
```

### B→A转换失败退出机制

当B类预算项目未能按期完成里程碑、无法转换为A类时，启动退出流程：

1. **预警触发**：里程碑延期>3个月，自动触发退出评估
2. **评估决策**：ST（经营管理团队）评审，判断是否继续投入
3. **退出执行**：
   - 已授予部分：按已使用金额核销，剩余额度释放回象限池
   - 未授予部分：直接释放
   - 知识资产：归档保存，评估是否可复用
4. **退出后评估**：总结失败原因，纳入基线数据库

### B→A转换管理阶段表

| 阶段 | 条件 | 系统动作 |
|------|------|---------|
| B类授予 | 年初 | 额度部分冻结（仅释放50-70%） |
| 季度检视 | 效果达标 | 批准B→A转换，全额锁定 |
| 季度检视 | 效果未达预期 | 继续冻结剩余额度 |
| B→A转换后 | 审批通过 | 解冻额度，可执行报销 |

每月向管委会提交《预算B→A转换专项报告》，含当月转换情况、未转换原因分析。

## 象限监控规则（操作版）

### 各象限监控指标

| 象限 | 监控指标 | 预警阈值 | 处理措施 |
|------|---------|---------|---------|
| **发展** | 执行率 | <70%→🟠橙色；<60%→🔴红色 | 优先追加预算审批 |
| **收缩** | 执行率 | >60%→🟠橙色；>70%→🔴红色 | 冻结非必要新增申请 |
| **稳定** | 执行率 vs 目标 | 偏离>10%→🟠橙色；>20%→🔴红色 | 调拨评估 |
| **探索** | 执行率+里程碑 | <30%→🟠橙色；<20%→🔴红色 | 重新评估资源配置 |

### 象限切换规则
```
发展象限项目执行率持续>95%（连续3个月）→评估是否需要调出至稳定象限
收缩象限项目执行率持续<30% → 评估是否需要追加资源或终止
探索象限项目B→A转换后 → 自动转入发展象限
稳定象限项目战略优先级提升 → 评估转入发展象限
```

## 预算八步贯通（操作流程）

```
第1步：年度预算申请（11-12月）
  各中心/部门提交次年预算需求 → Finance BP初审 → CFO汇总

第2步：预算评审（12月）
  CFO + 各中心负责人预算评审会 → 确定象限分配

第3步：预算授予（1月1日）
  系统初始化年度预算 → A类全额授予，B类50-70%授予

第4步：月度执行监控（每月）
  执行率跟踪 → 预警触发 → 滚动预测更新

第5步：季度复盘（每季度）
  PDCA-B季度复盘 → 调拨建议 → B类额度释放评估

第6步：预警响应与闭环（月度）
  预警登记 → 责任人响应 → 双签闭环 → 归档

第7步：半年度校准（如需要）
  重大偏差 → CFO审批 → 预算调整申请

第8步：年度决算（次年1月）
  全年执行汇总 → 未使用额度释放 → 转入战略储备
```

## 弹性预算机制（药企实践）

医药行业不确定性高（临床试验结果、审批时效、政策变化），需建立弹性预算机制：

**情景规划**：
| 情景 | 假设条件 | 预算调整幅度 | 触发条件 |
|------|---------|------------|---------|
| 乐观 | 核心管线III期成功+获批 | +20% | 临床终点达成 |
| 基准 | 按计划推进 | 0% | — |
| 悲观 | 核心管线失败或延期 | -30% | 临床失败/审批延期 |

**滚动预测**：
- 月度更新：每月根据最新数据更新预测
- 季度校准：每季度根据实际执行情况校准基准情景
- 半年重规划：每半年评估是否需要切换情景

## 研发双口径预算（华润医药实践）

华润医药在研发业务财务管理中建立双口径预算机制：

| 口径 | 定义 | 适用场景 | 确认时点 |
|------|------|---------|---------|
| 费用口径 | 按费用发生期间确认 | 经营分析、现金流管理 | 费用发生当期 |
| 资本化口径 | 按研发阶段确认 | 资产负债表、利润表 | 满足资本化条件时 |

资本化时点判断（参考）：
- 临床前研究：费用化
- I期临床：费用化
- II期临床：费用化（部分企业有条件资本化）
- III期临床：可资本化（需满足：技术可行+有完成意图+有能力完成+将来能产生经济利益）
- NDA申报：资本化
