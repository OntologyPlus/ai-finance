# 经营分析（9 诊断卡 + 4 框架）

> 对应方法论文档：[经营分析方法论.md](../../../经营分析方法论.md)
> 核心思想：把经营分析拆成 9 张结构化诊断卡（每张卡 = 1 个核心指标 + 1 个判断 + 1 段根因 + 1 组建议），辅以 4 个分析框架（杜邦/桥接/BCG/SAR），形成从宏观到微观的完整分析链路。

## 何时使用此技能

- 月度/季度经营分析会召开
- 预警汇总触发深度根因分析
- 用户请求差距分析、行动规划、战略评估、经营绩效回顾
- 触发词：经营分析、9 诊断卡、杜邦分析、桥接分析、BCG 矩阵、SAR、根因分析、行动建议、performance gap、action plan、root cause

## 工作流程（三段式）

```
9 卡诊断（监测 → 判定 → 根因 → 建议）
  → 4 框架深化（杜邦/桥接/BCG/SAR）
    → SAR 行动清单（必赢/改善/资源）
```

### 步骤 1：9 张诊断卡并行诊断

按"信号灯 → 数据证据 → 根因 → 建议"四段式逐卡扫描：

| 卡号 | 卡名 | 监测指标 | 信号灯主判定 |
|------|------|----------|------------|
| 1 | 收入健康度 | YTD 进度偏差 + 预算达成率 | -1pp / +2pp 分档 |
| 2 | 毛利质量 | 毛利率偏差 + 倒减法（品种 vs 结构） | ±1pp 分档 |
| 3 | 费用投放节奏 | 三层 YTD 进度偏差 | -1pp / -3pp 分档 |
| 4 | 品种结构 | 生命周期分布 + Top N 增速 | 成熟期占比 / 衰退期占比 |
| 5 | 渠道分化 | 院内 vs 院外增速差 | 5pp / 10pp 分档 |
| 6 | 利润真实性 | 商业利润 vs 经营利润差 | 5pp / 10pp 分档 |
| 7 | 商业化效率 | 品种推广费 ROI | 内部历史分位基准 |
| 8 | 政策风险 | 集采品种占比 + 毛利率变动 | 20% / 40% 分档 |
| 9 | 现金流质量 | DSO + 非经营性收益占比 + 收现比 | 30% / 60% 分档 |

完整 9 卡设计详见 [经营分析方法论 §3.2](../../../经营分析方法论.md#三经营诊断卡核心创新)。

### 步骤 2：4 框架深化

| 框架 | 擅长 | 在本技能的应用 |
|------|------|----------------|
| 杜邦分析（DuPont） | 利润率结构拆解 | 用于卡 1-3 的"利润率分解图"（管理版杜邦：毛利率 - 推广费 - 维持费 - 人力 - 研发） |
| 桥接分析（Bridge） | 利润偏差归因 | 用于从卡 1-3 输出 → 5 步利润桥接（预算 → 实际） |
| BCG 矩阵 | 产品组合分析 | 用于卡 4 的"产品组合象限图"（横轴增长率，纵轴收入规模） |
| SAR 框架 | 战略-行动-结果循环 | 用于卡 6-9 之后的"行动建议"组织（战略对齐 → 关键行动 → 预期结果） |

### 步骤 3：SAR 行动清单

把卡 1-9 + 4 框架的发现，转化为"必赢清单/改善清单/资源清单"三类行动：

- **必赢清单**：目标差距大且战略优先级高的项目（卡 1/2/3 的红灯输出）
- **改善清单**：执行差距大但可通过优化管理的项目（卡 3-5 的黄灯输出）
- **资源清单**：能力差距大需要补充资源的项目（卡 7-9 的关注项）

## 输出格式

```
# 经营分析报告 [期间]

## 第一部分：经营全景诊断
- 杜邦瀑布图：5 节点（毛利率 → 4 类费用）
- Top 3-5 核心判断（不超过 200 字）

## 第二部分：9 张诊断卡
- 卡 1-9：每张 4 段式（信号灯 + 判断 + 证据 + 根因 + 建议 + 待确认问题）
- 卡 1/3/6/8：关键卡 → 人工 review

## 第三部分：产品组合诊断
- BCG 4 象限散点图 + 每象限策略建议

## 第四部分：SAR 行动建议
- 战略对齐（与年度目标的距离）
- 关键行动（基于 9 卡发现，下季度 3-5 件事）
- 预期结果（如果执行到位，Q3/Q4 会有什么变化）
- 待业务负责人确认的问题
```

## 质量保证机制

按 [经营分析方法论 §5.2](../../../经营分析方法论.md#五ai-分析的质量标准)：

1. **完整数据切片**：AI prompt 必含当期所有相关数据切片（不是挖坑填空）
2. **四段式结构约束**：每张卡 = 判断-证据-根因-建议，缺一段视为不合格
3. **信号灯阈值规则化**：🔴/🟡/🟢 由规则判定，不由 AI 主观判断
4. **关键卡人工 review**：卡 1 收入健康度 / 卡 3 费用节奏 / 卡 6 利润真实性 / 卡 8 政策风险 需人工 review 后再发布
5. **AI 文字质量分级 L1-L4**：所有卡目标 L3 根因分析，关键卡目标 L4 战略洞察

## 信号灯判定规则

| 信号灯 | 含义 | 触发原则 |
|--------|------|---------|
| 🔴 红灯 | 重大风险，需立即关注 | 关键指标偏差超过预设临界值 |
| 🟡 黄灯 | 需要关注，建议观察 | 关键指标偏差在临界值附近 |
| 🟢 绿灯 | 健康，符合预期 | 关键指标偏差在合理范围内 |

**优先级规则**：当同一张卡的多个触发条件满足不同灯色时，**取最严重的灯色**。这确保诊断结论始终偏保守，避免"数据尚可但隐藏风险"的误判。

## 边界情况

- 当 9 卡全部绿灯时，输出"维持现有策略 + 监控下季边际变化"
- 当某张卡无数据时，标记"数据缺失待补充"，不强行生成判断
- 当多张卡红灯同时出现时，按 SAR 优先级组织：先卡 1（收入）→ 卡 3（费用）→ 卡 6（利润）
- 涉及政策/合规红线（如卡 8 集采）必须人工 review

## 数据驱动原则（不依赖 mock）

按 [经营分析方法论 §4.3](../../../经营分析方法论.md#四报告架构设计)：

- **报告 ≠ 数据库**：报告只做"传递判断"，不下钻、不筛选、不交互
- **数据流三层分离**：Excel → JSON → Markdown → HTML
- **可追溯**：HTML 报告中的任何数字都能反查到 JSON 和 Excel
- **不依赖前端 mock**：缺失数据回退 0 或显示"暂无数据"，不生成随机数
