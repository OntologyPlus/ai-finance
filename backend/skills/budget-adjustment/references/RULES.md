# 预算调整规则参考

## 硬规则（Hard Rules）

### HR-008 跨象限调拨须管委会批准
- **约束**：跨越象限边界的预算调拨必须经过管委会审批
- **说明**：不同象限代表不同战略优先级，跨象限调拨影响整体战略资源配置

## 调拨类型与规则

### 同象限内调拨
- **定义**：在同一战略象限内部的预算项目之间调拨
- **审批权限**：财经中心审批
- **说明**：同一象限内战略优先级一致，财经中心可自行决策

### 跨象限调拨
- **定义**：从某一战略象限调拨预算至另一象限
- **审批权限**：管委会审批
- **说明**：改变战略资源配置权重，须最高决策层审批

### 额度释放
- **定义**：预算项目结余释放，重新纳入可分配额度
- **触发条件**：
  - 项目完成后的剩余额度
  - B类预算未通过里程碑验证的额度
  - 战略调整后的压降额度
- **说明**：释放的额度可重新分配给其他项目

## 调整合规性检查清单

调整前须确认：

1. 调拨后双方额度合理性（不得出现负值或超额）
2. 是否符合硬规则约束（HR-001 总额控制）
3. 审批权限是否正确
4. 是否触发新的预警
5. 是否影响战略对齐度

## 调整效果模拟

提交调整申请前须模拟：

- 调拨后双方执行率变化
- 对四象限分布的影响
- 是否触发预警阈值
- 对战略举措完成度的影响
