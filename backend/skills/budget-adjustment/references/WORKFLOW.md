# 预算调整工作流程

## 1. 业务背景

预算执行过程中，由于战略调整、市场变化或执行偏差，可能需要进行预算调整。调整包括同象限内调拨、跨象限调拨和额度释放。

核心管理诉求：如何在保障战略方向不变的前提下，灵活应对执行偏差？调拨后如何确保不突破年度预算总额？

## 2. 管理政策

- **同象限调拨**：财经中心审批（同一象限战略优先级一致，风险较低）
- **跨象限调拨**：须管委会批准（改变战略资源配置权重，风险较高）
- **额度释放**：预算项目结余释放，重新纳入可分配额度
- **总额控制**：任何调整不得突破年度预算总额（HR-001）
- **先批后用**：任何支出须先完成预算申报与审批，严禁事后补批

## 3. 流程设计

### 3.1 调拨申请

业务部门或财经中心发现需要调拨时：

1. 填写预算调整申请单
2. 明确调拨原因（超预算/结余/战略调整）
3. 明确调出方和调入方（含预算ID）
4. 明确调拨金额和期望生效时间

### 3.2 合规性校验

系统自动校验：

| 校验点 | 规则 |
|-------|------|
| 总额控制 | 调整后总预算不得超过年度预算总额 |
| 额度有效性 | 双方调整后额度不得为负值 |
| 象限变更 | 跨象限调拨须标记，走管委会审批 |
| 预警影响 | 评估是否会触发新预警或消除现有预警 |

### 3.3 审批流程

**同象限调拨审批链**：

| 步骤 | 审批人 | 说明 |
|------|--------|------|
| 1 | 调出方部门负责人 | 确认调出意愿和原因 |
| 2 | 调入方部门负责人 | 确认调入需求和用途 |
| 3 | 财经中心分管领导 | 审核调拨合理性和合规性 |
| 4 | 财经中心总经理 | 审批通过 |

**跨象限调拨审批链**：

| 步骤 | 审批人 | 说明 |
|------|--------|------|
| 1 | 调出方部门负责人 | 确认调出意愿和原因 |
| 2 | 调入方部门负责人 | 确认调入需求和用途 |
| 3 | 财经中心分管领导 | 审核调拨对战略资源配置的影响 |
| 4 | 管委会 | 最终审批，评估战略权重变化 |

### 3.4 系统执行

审批通过后系统自动执行：

1. 更新调出方和调入方的预算额度
2. 记录调整轨迹（时间、操作人、审批链、调整前后金额）
3. 更新预算项目状态
4. 重新检查预警状态

### 3.5 额度释放流程

1. 识别可释放额度（项目完成/预算结余/B类未通过验证）
2. 财经中心确认释放金额
3. 系统执行释放，额度返回可分配池
4. 记录释放轨迹

## 4. 角色定义

| 角色 | 发起 | 审核 | 批准 | 归档 |
|------|------|------|------|------|
| **业务部门负责人** | ✅ 调拨申请 | ✅ 确认调拨原因 | — | — |
| **财经中心** | ✅ 主动调拨建议 | ✅ 合规性校验 | ✅ 同象限调拨审批 | ✅ 调拨记录存档 |
| **财经中心分管领导** | — | ✅ 调拨影响评估 | — | — |
| **管委会** | — | — | ✅ 跨象限调拨审批 | — |

## 5. 时效要求

| 节点 | 时效要求 | 责任方 |
|------|---------|--------|
| 调拨申请提交 | 发现需求后3个工作日内 | 业务部门/财经中心 |
| 同象限调拨审批完成 | 申请后5个工作日 | 财经中心 |
| 跨象限调拨审批完成 | 申请后10个工作日（含管委会审阅） | 管委会 |
| 系统执行 | 审批通过后1个工作日 | 财经中心预算管理部 |
| 额度释放 | 确认释放后2个工作日 | 财经中心预算管理部 |

## 6. 违规处理

| 违规场景 | 处理方式 |
|---------|---------|
| 未经审批擅自调拨 | 视为无效，恢复原额度，责任人通报批评 |
| 调拨后出现负额度 | 立即冻结，追回超额部分，重新审批 |
| 跨象限调拨未报管委会 | 撤销调拨，责任人上报管委会 |
| 虚假调拨理由骗取额度 | 冻结全部相关预算，上报审计 |
