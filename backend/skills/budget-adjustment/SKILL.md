# 预算调整

## 何时使用此技能
当在执行期间调整预算分配、在预算项目之间调拨资金、释放未使用额度，或用户询问预算调拨规则、"预算调整"、"调拨"、"额度释放"、"同象限调拨"、"跨象限调拨"时使用。预算执行出现持续偏差需要再平衡或战略变化影响资源配置时也会触发。

## 工作流程

本技能采用**验证-修复模式**：分析需求→确定类型→校验合规→模拟效果→执行，每步都有验证和修正循环。

### 步骤1：分析调整需求
- **为什么**：了解调整需求的根本原因可以防止治标不治本。
- 确认调整原因：
  - 当前项目超预算（需要追加额度）
  - 其他项目有预算结余（可以释放额度）
  - 战略变化需要重新分配
- 识别涉及的预算项目和象限
- 计算调整金额

### 步骤2：确定调整类型
- **为什么**：不同调整类型有不同的审批要求和风险等级。
- 对调整进行分类：
  - **同象限内调拨**：财经中心审批（风险较低，战略优先级一致）
  - **跨象限调拨**：须管委会批准（HR-008，风险较高，改变战略权重）
  - **额度释放**：预算项目结余释放（无调拨目标，返回额度池）

### 步骤3：合规性校验
- **为什么**：无效调整会破坏预算模型并可能违反硬性约束。
- 校验硬规则：
  - HR-001：调整后预算总额仍须在 SP/BP 限额内
  - HR-008：跨象限调拨须管委会批准
  - 双方额度必须有效（调拨后不得出现负值）
  - 审批权限与调整类型匹配
- 如果校验失败，识别问题并建议修正方案

### 步骤4：模拟调整效果
- **为什么**：预览效果帮助决策者在执行前了解后果。
- 计算调整后双方的额度分配
- 评估对执行率的影响
- 检查是否会触发新的预警
- 评估对战略对齐度和象限分布的影响

### 步骤5：执行调整
- **为什么**：正式执行创建可审计的变更记录。
- 提交审批：
  - 同象限 → 财经中心
  - 跨象限 → 管委会
- 审批通过后：
  - 执行额度变更
  - 更新预算项目状态
  - 记录调整轨迹（时间、操作人、原因、调整前后金额）
  - 重新检查预警（调整可能消除或触发预警）

## 输出格式
```
预算调整申请
- 类型：[同象限调拨/跨象限调拨/额度释放]
- 调出方：[预算项目编号 + 名称]
- 调入方：[预算项目编号 + 名称]（额度释放不适用）
- 金额：[N] 万元
- 原因：[超预算/结余/战略调整]
- 调整后状态：
  - 调出方：[调整前 N → 调整后 N] 万元
  - 调入方：[调整前 N → 调整后 N] 万元
- 合规性：[全部通过 / 发现 N 项问题]
- 审批权限：[财经中心 / 管委会]
- 预警影响：[消除 N 条预警 / 触发 N 条预警]
```

## 边界情况
- 如果跨象限调拨会使某象限低于最低阈值，标记为管委会专项审查
- 如果调整会在调出方触发红色预警，无论调拨类型都须管委会审查
- 同象限调拨可批量处理；跨象限调拨须逐项审批
