# 报表出具

## 何时使用此技能
在月度/季度/年度报表出具周期，或用户请求月度快报、季度分析报告、年度复盘报告时使用。触发词包括："月度快报"、"季度报告"、"年度复盘"、"执行快报"、"经营分析报告"、"generate report"、"monthly report"、"quarterly report"、"annual review"。

## 工作流程

本技能采用**模板填充模式**：收集数据→填充报告模板→输出，每种报告类型有预定义结构。

### 步骤1：确定报告类型
- **为什么**：不同报告类型服务不同受众，有不同的内容要求。
- 识别请求的报告类型：
  - **月度快报**：预算执行进度、预警汇总（次月第 3 个工作日前出具）
  - **季度报告**：3GAP+3List 分析、战略评估（次季度第 10 个工作日前出具）
  - **年度复盘**：全年总结、PDCA 闭环率（次年第 15 个工作日前出具）

### 步骤2：收集数据
- **为什么**：报告质量完全取决于数据的完整性和准确性。
- 收集所需数据：
  - 预算执行数据（按科目/项目/象限）
  - 预警记录和闭环情况
  - 审批流程统计
  - 战略举措完成度
  - 3GAP 分析结果（季度报告需要）
  - PDCA 闭环指标（年度报告需要）

### 步骤3：填充报告模板
- **为什么**：标准化模板确保所有报告的一致性和完整性。
- 选择并填充对应模板：
  - 月度快报：执行摘要、执行进度表、预警汇总、关键指标、本月重点事项
  - 季度报告：执行摘要、3GAP 结果、3List 行动清单、战略执行评估、象限分析、下季度重点
  - 年度复盘：执行摘要、全年执行总结、PDCA 闭环率、改进建议、下年度规划
- 详细报告模板请读取 `references/TEMPLATES.md`

### 步骤4：格式校验
- **为什么**：一致的格式使报告更容易阅读和跨期间比较。
- 应用格式规范：
  - 金额统一使用万元
  - 偏差率保留两位小数
  - 百分比保留一位小数
  - 所有数据标注出处
  - 底部标注报告版本和生成时间
- 详细格式规范请读取 `references/RULES.md`

## 输出格式
```
[报告类型] - [期间]
版本：[X.X] | 生成时间：[YYYY-MM-DD HH:mm]

[按模板结构的报告内容]

---
数据来源：[系统名称 / 报表编号 / 统计口径]
报告版本：[X.X]
```

## 边界情况
- 如果某期间数据不完整，用现有数据生成报告，并将缺失部分明确标记为"数据待补"
- 如果季中请求季度报告，确认这是特殊请求还是对报表周期的误解
- 年度报告需要四个季度的数据——生成前确保季度数据一致性
