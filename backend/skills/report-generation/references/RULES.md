# 报表出具规则参考

## 报告格式规范

### 数值规范
- **金额单位**：统一使用万元
- **偏差率**：保留两位小数
- **百分比**：保留一位小数

### 数据来源规范
- 所有数据须标注出处（系统名称/报表编号/统计口径）
- 跨系统数据须说明对账结果
- 异常数据须附说明

### 通用结构要求
1. 执行摘要（一页以内）
2. 正文按主题分章节
3. 附录包含详细数据表
4. 底部标注报告版本和生成时间

## 报告类型与出具周期

### 月度快报
- **出具周期**：每月12日数据定稿后5个工作日内完成
- **数据截止**：月末最后一天
- **核心内容**：预算执行进度、预警汇总、关键指标
- **接收对象**：经营分析小组成员

### 季度报告
- **出具周期**：每季度在管委会上进行季度总结陈述（管委会会议前7天提交材料）
- **数据截止**：季末最后一天
- **核心内容**：3GAP 分析、3List 行动清单、战略执行评估
- **接收对象**：管委会

### 年度复盘
- **出具周期**：次年预算采集前完成
- **数据截止**：年末最后一天
- **核心内容**：全年执行总结、PDCA 闭环率、改进建议
- **接收对象**：管委会

## 三中心分工

| 中心 | 分析范围 |
|------|---------|
| **财经中心** | 利润表现、收入进度、管理及研发费用中的维持性费用 |
| **运营中心** | 各经营责任中心收入进展、品种表现、新增渠道表现、新产品上市情况、市场推广费用使用情况、销售团队人力情况 |
| **人力中心** | 集团整体人力编制及人力成本使用情况、人力资源管理问题 |

## 数据定稿唯一性原则
- 每月12日为数据最后定稿时间，定稿后未经授权不得调整
- 管委会有权对报表提出质疑，财经中心须在1个工作日内答复

## 违规处理

| 违规场景 | 处理方式 |
|---------|---------|
| 虚假瞒报经营数据 | 退回数据，情节严重者上报管委会及审计部 |
| 未经授权调整已定稿数据 | 数据无效，恢复至最近一次授权版本，责任人记过 |
| 数据不按统一利润表格式填报 | 退回重填，影响汇总进度者通报批评 |
