# 报表出具规则参考

## 报告格式规范

### 数值规范
- **金额单位**：统一使用万元
- **偏差率**：保留两位小数
- **百分比**：保留一位小数

### 数据来源规范
- 所有数据须标注出处（系统名称/报表编号/统计口径）
- 跨系统数据须说明对账结果
- 异常数据须附说明

### 通用结构要求
1. 执行摘要（一页以内）
2. 正文按主题分章节
3. 附录包含详细数据表
4. 底部标注报告版本和生成时间
