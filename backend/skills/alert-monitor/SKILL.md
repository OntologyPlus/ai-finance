# 预警监控

## 何时使用此技能
当用户需要监控预算执行情况、检查预警或警报、查看计划偏差，或询问预算超支、执行率超阈值、里程碑延期、预警状态时使用。触发词包括："检查预警"、"有什么预警"、"预算超支"、"执行偏差"、"里程碑延期"、"预警"、"超预算"、"执行偏差"。

## 工作流程

本技能采用**分支模式**：根据预警类型（月度/季度/里程碑），执行不同的扫描路径。

### 步骤1：确定扫描类型
- **为什么**：不同预警类型需要不同的数据源和阈值规则。
- 确定需要的扫描模式：
  - 月度执行进度扫描
  - 季度滚动预测扫描
  - 里程碑延期扫描
  - 全量扫描（三种模式同时执行）

### 步骤2：执行月度执行扫描
- **为什么**：月度数据是预算健康状况最频繁的指标。
- 获取本月累计执行数据
- 与计划进度阈值对比：
  - 累计执行 > 计划 105% → 蓝色预警（SR-001）
  - 累计执行 > 计划 110% → 黄色预警（SR-002）
  - 实际 > 年度预算 → 红色预警（SR-003）
  - 单项/单供应商偏差 > 50 万 → 红色预警（HR-011）
- 详细阈值定义请读取 `references/RULES.md`

### 步骤3：执行季度滚动预测扫描
- **为什么**：滚动预测能发现月度数据单独无法捕捉的中期趋势。
- 收集最新季度滚动预测数据
- 计算预测与实际偏差：
  - 偏差 > 10% → 蓝色预警（SR-004）
  - 偏差 > 20% → 黄色预警（SR-005）
  - 偏差 > 30% → 红色预警（SR-006）
- 分析偏差趋势（恶化/改善/稳定）

### 步骤4：执行里程碑扫描
- **为什么**：里程碑延期直接影响 B→A 转换资格和战略举措进展。
- 收集项目里程碑计划和当前状态
- 检查三个维度：
  - 时间维度：项目进度 vs 时间进度
  - 成本维度：成本消耗 vs 时间进度
  - 累计维度：累计执行率 vs 年度进度
- 三维度同时触发 → 红色预警 + 追加预算建议
- B类项目里程碑延期直接影响 B→A 转换（HR-009）

### 步骤5：L1 专项规则检查
- **为什么**：某些项目类型需要超越标准阈值的专项监控。
- 执行 L1 专项规则检查：
  - B1：无形资产/工程/固定资产专项
  - B2：研发阶段专项（IND/NDA/III期）
  - B4：税务合规专项
  - B5：ROI 专项
  - B6：人头联动专项
  - B8：投资阶段专项（单项 > 500 万 → 红色预警）

### 步骤6：推送预警
- **为什么**：预警只有在正确的人于响应时限内收到通知时才有价值。
- 按预警级别确定通知对象（响应时限见 `references/RULES.md`）
- 设置响应时限：蓝色 72h、黄色 48h、橙色 24h、红色 4h
- 跟踪预警闭环状态
- 响应时限到期未闭环则自动升级（HR-003）

## 输出格式
```
预警报告 [日期]
- 扫描类型：[月度/季度/里程碑/全量]
- 预警总数：[N] 条
  - 红色：[N] | 橙色：[N] | 黄色：[N] | 蓝色：[N]
- 预警明细：
  - [级别] [预算项目] [偏差%] [响应时限] [状态]
- 待闭环：[N] 条
- 已升级：[N] 条
```

## 边界情况
- 如果当前期间无数据，报告"无数据"而非"无预警"
- 如果单个预算项目触发多个预警，合并为最高级别
- B类项目始终同时检查 HR-009（里程碑延期）和标准阈值
