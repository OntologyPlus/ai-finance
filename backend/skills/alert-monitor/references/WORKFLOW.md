# 预警监控工作流程

## 月度执行进度扫描流程

1. **数据采集**：从系统获取本月累计执行数据
2. **基准对比**：与年度计划进度对比
3. **阈值判定**：
   - 执行率 > 105% → 蓝色预警（SR-001）
   - 执行率 > 110% → 黄色预警（SR-002）
   - 执行率 > 年度预算 → 红色预警（SR-003）
   - 单项/单供应商偏差 > 50 万 → 红色预警（HR-011）
4. **预警记录**：生成预警记录，记录偏差金额和比例
5. **通知推送**：按预警级别推送通知

## 季度滚动预测扫描流程

1. **获取预测数据**：收集本季度最新滚动预测
2. **偏差计算**：计算预测与实际的偏差率
3. **阈值判定**：
   - 偏差 > 10% → 蓝色预警（SR-004）
   - 偏差 > 20% → 黄色预警（SR-005）
   - 偏差 > 30% → 红色预警（SR-006）
4. **趋势分析**：判断偏差趋势（恶化/改善/稳定）
5. **预警记录与通知**：生成预警并推送

## 里程碑预警流程

1. **获取里程碑计划**：收集各项目的计划里程碑
2. **三维度对比**：
   - 时间维度：项目进度 vs 时间进度
   - 成本维度：成本消耗 vs 时间进度
   - 累计维度：累计执行率 vs 年度进度
3. **判定规则**：
   - 任一维度偏差 → 黄色预警
   - 三维度同时触发 → 红色预警 + 追加预算建议
4. **B类项目优先**：B类项目里程碑延期直接影响 B→A 转换

## 预警推送流程

1. **确定通知对象**：按预警级别确定
   - 蓝色 → 预算负责人
   - 黄色 → 部门负责人
   - 橙色 → 中心总经理
   - 红色 → 管委会
2. **设定响应时限**：蓝72h / 黄48h / 橙24h / 红4h
3. **推送通知**：通过系统通知、邮件等方式推送
4. **监控响应**：跟踪预警闭环状态
5. **超时升级**：响应时限到期未闭环则自动升级
