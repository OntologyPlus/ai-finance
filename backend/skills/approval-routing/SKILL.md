# 审批路由

## 何时使用此技能
当确定报销审批路径、查询审批链、检查管控级别，或用户询问"谁审批这个"、"审批流程"、"审批路径"、"管控级别"、"超时升级"时使用。审查待审批、检查升级状态或配置审批阈值时也会触发。

## 工作流程

本技能采用**分支模式**：根据 L3 科目管控级别选择不同的审批路径。

### 步骤1：确定管控级别
- **为什么**：管控级别决定整个审批链的复杂度，是首要的分支决策。
- 查询 L3 科目管控标签：
  - **强管控**：需要组织线 + 法人线双线审批（HR-002）
  - **中心弱管控**：仅中心内部审批
  - **组合管控**：根据金额阈值确定路径
  - **不管控**：直接核销，无需审批
- 详细管控级别定义请读取 `references/RULES.md`

### 步骤2：组织管理线路由
- **为什么**：组织线确保了解业务背景的人进行业务层面审核。
- 审批链：
  - 部门负责人（所有费用必经）
  - 中心总经理（金额超阈值时）
  - 院外渠道中心总经理（仅"院外"类型预算进入）
- 每个节点须在 3 个工作日内完成审批

### 步骤3：法人架构线路由
- **为什么**：法人线确保财务合规和正确的会计处理。
- 审批链：
  - 法人财务负责人（合规性和预算可用性检查）
  - 法人或授权人（最终审批）
- 仅在强管控或组合管控超过阈值时触发

### 步骤4：监控超时并升级
- **为什么**：审批瓶颈影响业务效率，自动升级防止流程延误。
- 跟踪每个节点的响应时间
- 升级规则（HR-005）：
  - 蓝色级别：3 天 → 升级至上级管理者
  - 黄色级别：2 天 → 升级至中心总经理
  - 橙色级别：1 天 → 升级至法人负责人
  - 红色级别：立即 → 升级至管委会
- 超时同时通知申请人和升级对象

### 步骤5：处理审批结果
- **为什么**：最终结果决定流水线中的下一步操作。
- **通过**：进入核销流程，通知申请人
- **驳回**：退回申请人并说明驳回理由，不扣减预算
- **超时**：自动升级，通知申请人升级情况

## 输出格式
```
审批路径 [报销单编号]
- 管控级别：[强管控/中心弱管控/组合管控/不管控]
- 组织管理线：[步骤1 → 步骤2 → ...]
- 法人架构线：[步骤1 → 步骤2 → ...]（如适用）
- 当前节点：[节点名称 + 审批人]
- 节点状态：[待审批/已通过/已驳回/已超时]
- 已耗时：[N] 天（时限：[N] 天）
- 下一步：[等待审批/已升级/已完成]
```

## 边界情况
- 如果费用为"院外渠道"预算，在部门负责人和财务BP之间插入院外渠道中心总经理审批节点
- 如果某节点审批人请假，系统自动委托给指定备份审批人
- 如果两条线审批完成时间不同，后完成的审批确认整个流程完成
