# 全链路影响评估

## 核心能力
- 预算变更影响评估：评估预算调拨/调整对五个域的影响
- 费用超支影响评估：评估费用超支的跨域影响
- 战略调整影响评估：评估战略方向调整的影响
- 影响追踪：追踪已发生操作的实际影响
- 缓解建议：对负面影响提出缓解方案

## 影响评估维度
1. 预算域 → 可用额度、执行率、A/B分类
2. 费用域 → 审批路径、管控级别
3. 预警域 → 预警阈值、预警级别
4. 现金流域 → 付款排期、流动性
5. 战略域 → 战略覆盖率、象限分布

## 方法论参考

| 方法论 | 引用原因 |
|--------|---------|
| CFO分析问题定义标准 | 影响评估需按战略层/经营层/操作层分级框架确定评估层级，明确影响的业务对象和分析维度 |
| CFO交互标准与沟通范式 | 影响评估结果需根据CFO决策场景选择沟通范式，战略调整影响按战略层范式呈现，操作影响按操作层范式呈现 |
