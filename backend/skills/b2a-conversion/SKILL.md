# B→A 转换

## 何时使用此技能
当 B类预算项目达成里程碑目标需要转换为 A类冻结预算，或用户询问 B转A 转换、里程碑验证、预算分类变更、"B转A"、"B类转A类"、"里程碑达标"、"弹性转冻结"时使用。里程碑评审显示 B类项目绩效值得正式预算分配时也会触发。

## 工作流程

本技能采用**验证-修复模式**：验证里程碑→检查条件→申请审批→执行转换，每步都有严格验证。

### 步骤1：验证里程碑完成情况
- **为什么**：B→A 转换是对冻结资源的承诺，必须有成功执行的证据支撑。
- 检查 B类预算项目的里程碑完成状态
- 收集里程碑达标证据：
  - 项目交付物验收报告
  - 阶段性成果评审意见
  - 关键指标达成数据
- SR-007：转换需要里程碑达标证据——无证据不得转换
- 详细验证标准请读取 `references/RULES.md`

### 步骤2：检查转换条件
- **为什么**：即使有里程碑证据，系统性约束也可能阻止转换。
- HR-004：B类预算授予比例不超过年度额度的 30%
- 确认当前 B类授予比例
- 计算转换后 A类冻结额度
- 确认验证季度（Q1/Q2/Q3/Q4）

### 步骤3：提交转换申请
- **为什么**：正式申请创建可审计记录并触发审批流程。
- 填写 B→A 转换申请：
  - 预算项目编号和名称
  - 当前 B类金额
  - 目标 A类冻结金额
  - 里程碑证据引用
  - 验证季度

### 步骤4：审批流程
- **为什么**：B→A 转换改变预算风险画像，需要跨职能验证。
- 财经中心初审：验证材料完整性和数据准确性
- 管委会审批：评估对战略资源配置的影响
- 审批决定：
  - 通过 → 进入执行
  - 驳回 → 退回 B类并附反馈
  - 有条件通过 → 明确附加要求

### 步骤5：执行转换
- **为什么**：系统执行完成转换并更新所有相关预算记录。
- 将 B类预算金额转换为 A类冻结金额
- 更新预算项目分类（B → A）
- HR-009：记录任何里程碑延期历史供将来参考
- HR-010：释放未转换的未使用 B类额度
- 记录转换轨迹（时间、操作人、证据引用、转换前后金额）

## 输出格式
```
B→A 转换报告
- 预算项目：[编号 + 名称]
- 里程碑：[名称 + 完成日期]
- 证据：[证据文件清单]
- 当前 B类金额：[N] 万元
- 转换 A类金额：[N] 万元
- 转换后 B类授予比例：[N]%（上限：30%）
- 验证季度：[Q1/Q2/Q3/Q4]
- 审批状态：[待审批/已通过/已驳回]
- 未使用 B类额度释放：[N] 万元
```

## 边界情况
- 如果里程碑部分完成（部分子里程碑达成），不执行转换——等待全部完成或重新评估里程碑定义
- 如果转换后 B类授予比例超过 30%，仅转换至上限，剩余部分保留为 B类
- 如果项目部分成功但有重大问题，建议"B类延期"而非转换

## B→A转换退出机制

当B类项目里程碑延期超过3个月，须启动退出评估流程：

### 退出流程

1. **预警触发**：里程碑延期>3个月，系统自动触发退出评估预警
2. **评估决策**：ST评审会决定是否继续投入
   - 继续投入：设定新的里程碑节点，延期期间冻结预算追加
   - 退出：进入退出执行阶段
3. **退出执行**：
   - 已授予部分：完成已发生费用核销，剩余预算释放
   - 未授予部分：直接释放
   - 知识资产归档：项目文档、数据、经验教训归入基线数据库
4. **退出后评估**：
   - 总结失败原因（市场变化/技术风险/资源不足/管理问题）
   - 纳入基线数据库，供后续项目参考
   - 更新战略意图L2标签，标记该方向已退出
