# B→A 转换工作流程

## 1. 业务背景

B类预算（待定型）在年初授予0%，不锁定额度。当项目有明确进展并达到里程碑后，可申请B→A转换，转换通过后全额锁定，方可执行报销。

核心管理诉求：如何确保B类预算只在验证有效后才释放额度？如何防止虚假里程碑骗取转换？

## 2. 管理政策

- **A类预算（确定型）**：立项即全额授予，额度锁定，执行中不做弹性调整
- **B类预算（待定型）**：年初授予0%，按进展情况决定是否B→A转换后方可支出
- **B→A转换条件**：须有明确进展和里程碑达标证据
- **效果未达预期**：冻结剩余额度，不批准转换
- **月度报告**：每月向管委会提交《预算B→A转换专项报告》
- **项目化管理门槛**：年度预算超过50万元，或任何新增项目单笔超过20万元，须纳入项目化管理

## 3. 流程设计

### 3.1 接收阶段一输出

- 财经中心接收阶段一批准的年度预算总额及各中心框架，作为阶段二的输入
- 无需重新申报或协商，直接进入授予执行阶段

### 3.2 A/B 分类授予

- 财经中心将年度预算总额，按A/B二类差异化授予方式分配至各中心
- A类须先完成立项审批，才能分配预算额度，全额锁定
- B类按季度里程碑，分批授予；每批次须有效果验证才能释放

### 3.3 系统锁定

- A/B类额度在系统中锁定
- 锁定后方可执行报销

### 3.4 B→A 转换申请

业务部门在有明确进展后：

1. 向财经中心提交B→A转换申请
2. 提供里程碑达标证据：
   - 项目交付物验收报告
   - 阶段性成果评审意见
   - 关键指标达成数据
3. 明确验证季度（Q1/Q2/Q3/Q4）

### 3.5 季度检视

每季度首月5日前，财经中心检视B类转换进展：

| 状态 | 处理 |
|------|------|
| 达标 | 批准转换，全额锁定 |
| 未达标 | 继续冻结，不批准转换 |
| 虚假申请 | 立即冻结剩余额度，追回已转换额度，重新审批 |

### 3.6 月度专项报告

每月末向管委会提交《预算B→A转换专项报告》，包含：

- 当月B→A转换情况
- 未转换原因分析
- 未达标冻结说明

### 3.7 审批流程

| 步骤 | 审批人 | 说明 |
|------|--------|------|
| 1 | 业务部门 | 提交B→A转换申请和里程碑证据 |
| 2 | 各中心财经BP | 核实数据准确性 |
| 3 | 财经中心预算管理部 | 审核材料完整性和合规性 |
| 4 | 财经中心分管领导 | 复核B类转A类 |
| 5 | 管委会 | A类项目终审+B→A转换报告审阅 |

## 4. 角色定义

| 角色 | 发起 | 审核 | 批准 | 归档 |
|------|------|------|------|------|
| **财经中心预算管理部** | ✅ 编制AB授予方案 | ✅ A/B分类核定 | — | ✅ 预算库维护 |
| **各中心财经BP** | ✅ 组织本中心确认 | ✅ 数据核实+分类确认 | — | ✅ 协助存档 |
| **业务部门** | ✅ 提交A类立项申请 / B→A转换申请 | — | — | — |
| **财经中心分管领导** | — | ✅ B类转A类复核 | ✅ A类额度+B类转A审批 | — |
| **管委会** | — | — | ✅ A类项目终审+B转A报告审阅 | — |

## 5. 时效要求

| 节点 | 时效要求 | 责任方 |
|------|---------|--------|
| A类预算立项申请提交 | 按项目立项时间，无固定截止 | 业务部门 |
| A类预算审批完成 | 立项申请提交后5个工作日 | 财经中心 |
| B类转A类申请提交 | 每季度首月5日前 | 各中心财经BP |
| B类转A类审批完成 | 申请提交后5个工作日 | 财经中心分管领导 |
| 《预算B→A转换专项报告》提交 | 每月末 | 财经中心预算管理部 |
| 系统A/B两类额度全部锁定 | 阶段一终审后5个工作日内 | 财经中心预算管理部 |

## 6. 违规处理

| 违规场景 | 处理方式 |
|---------|---------|
| 未经审批调整已锁定预算 | 退回申请，视为无效；情节严重者上报管委会 |
| A类预算超额度但未先立项 | 立即冻结超额部分，责令补充立项后再行使用 |
| B类虚假申请B→A转换骗取额度 | 立即冻结剩余额度，追回已转换额度，重新审批 |
| 项目里程碑造假或挪用预算 | 冻结全部项目预算，追回挪用款项，上报审计 |
