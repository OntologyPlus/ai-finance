# B→A 转换规则参考

## 硬规则（Hard Rules）

### HR-004 B类预算授予比例限制
- **约束**：B类预算授予比例不超过年度额度的 30%
- **说明**：控制前置探索类预算的风险敞口，避免过多资源投入不确定项目

### HR-009 里程碑延期预警
- **触发条件**：B类预算项目里程碑未按时完成
- **预警级别**：黄色预警
- **说明**：里程碑延期直接影响 B→A 转换资格，须及时提醒和纠偏

### HR-010 未使用额度释放
- **触发条件**：B类预算项目未通过里程碑验证
- **动作**：自动释放/冻结未使用额度
- **说明**：效果未达预期时冻结剩余额度，防止无效消耗

## 软规则（Soft Rules）

### SR-007 B→A 转换里程碑达标证据
- **约束**：B→A 转换必须提供里程碑达标证据
- **证据类型**：
  - 项目交付物验收报告
  - 阶段性成果评审意见
  - 关键指标达成数据
- **说明**：无达标证据不得执行转换

## B→A 转换条件检查清单

转换前须逐项确认：

1. [ ] 里程碑是否全部完成
2. [ ] 达标证据是否充分
3. [ ] 当前 B 类授予比例是否超标（HR-004）
4. [ ] 转换后 A 类冻结额度计算是否正确
5. [ ] 验证季度是否明确（Q1/Q2/Q3/Q4）

## 转换审批流程

| 步骤 | 审批人 | 说明 |
|------|--------|------|
| 1 | 业务部门 | 提交B→A转换申请和里程碑证据 |
| 2 | 各中心财经BP | 核实数据准确性 |
| 3 | 财经中心预算管理部 | 审核材料完整性和合规性 |
| 4 | 财经中心分管领导 | 复核B类转A类 |
| 5 | 管委会 | A类项目终审+B→A转换报告审阅 |

## 转换执行动作

- B 类预算额度 → A 类冻结额度
- 更新预算项目类别（B → A）
- 记录转换轨迹（含时间、操作人、证据引用）
- 更新象限归属（如适用）

## B类管理要求

- B类在有明确进展后，业务部门向财经中心提交B→A转换申请
- 每季度检视B类转换进展：达标则批准转换，全额锁定；未达标则继续冻结
- 每月向管委会提交《预算B→A转换专项报告》，含当月转换情况、未转换原因分析
- B类虚假申请B→A转换骗取额度 → 立即冻结剩余额度，追回已转换额度，重新审批
