# 零基预算审视

## 何时使用此技能
在零基预算审视期间、需要从零开始评估支出必要性、决策包排序与综合、或用户询问"零基预算"、"ZBB"、"决策包"、"预算审视"、"必要性评估"时使用。

## 工作流程

本技能采用**流水线模式**：启动审视→创建决策单元→编制决策包→排序→综合预算，各步骤有明确的顺序依赖。

### 步骤1：启动零基预算审视
- **为什么**：零基预算要求从零开始，不参考历史预算，每一分钱都需要重新证明其必要性。
- 确定审视期间和总预算约束
- 创建审视记录，状态设为"启动"

### 步骤2：创建决策单元
- **为什么**：将组织拆分为独立的决策单元，每个单元独立证明其存在价值。
- 每个决策单元定义名称、负责人和范围
- 审视状态自动转为"编制中"
- HR-023：每个决策单元必须编制三个级别的决策包（最低/当前/增强）

### 步骤3：编制决策包
- **为什么**：决策包是零基预算的核心——每个单元需要说明不同投入水平下的产出。
- 三个级别：
  - **最低包**：维持基本运转的最低投入，不提供则单元无法运作
  - **当前包**：维持当前服务水平的投入
  - **增强包**：在当前基础上增加投入以获得更大产出
- HR-024：最低包金额不得超过当前包的60%
- 每个包需说明必要性（justification）

### 步骤4：排序
- **为什么**：在总预算约束下，必须对决策包进行优先级排序。
- 排序规则：
  1. 最低包优先保障（所有最低包必须满足）
  2. 同级别按战略对齐度降序
  3. 同对齐度按金额升序（性价比优先）
- 计算约束线：累计金额不超过总预算约束的截止点

### 步骤5：综合预算方案
- **为什么**：基于排序结果，在总预算约束内合成最终预算方案。
- 约束线内的包纳入预算方案
- 超出约束线的包标记为"暂缓"
- HR-025：综合预算方案须经管委会审批后方可执行
- 生成各决策单元的预算汇总

## 输出格式
```
零基预算审视报告 [期间]
- 总预算约束：[N] 万元
- 决策单元：[N] 个
- 决策包：[N] 个（最低[N]/当前[N]/增强[N]）
- 约束线内：[N] 个包，[N] 万元
- 暂缓：[N] 个包，[N] 万元
- 预算利用率：[N]%
```

## 边界情况
- 如果最低包总额已超过总预算约束，标记为"预算不足"并建议增加约束或削减最低包
- 如果决策单元未编制三个级别的包，排序时跳过缺失的级别
- 增强包的战略对齐度需额外验证，默认乘以0.6系数
