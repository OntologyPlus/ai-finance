# 费用报销工作流程

## 报销提交流程

1. **收集报销信息**
   - 报销金额、费用类型、发生日期
   - 关联的预算项目ID（必填）
   - 发票/凭证附件

2. **发票合规性校验**
   - 发票真实性验证
   - 发票金额与报销金额一致性
   - 发票有效期检查

3. **预算项目挂载**
   - 查询预算项目状态
   - 确认预算可用额度
   - 挂载预算ID（HR-001 校验）

## 管控路由决策树

```
报销单提交
  │
  ├─ 查询 L3 科目管控标签
  │
  ├─ 强管控？
  │   └─ 是 → 组织线 + 法人线双线审批
  │
  ├─ 中心弱管控？
  │   └─ 是 → 中心内部审批
  │
  ├─ 组合管控？
  │   └─ 是 → 按金额确定审批路径
  │           ├─ 低于阈值 → 中心内部审批
  │           └─ 超过阈值 → 双线审批
  │
  └─ 不管控？
      └─ 是 → 直接核销
```

## 双线审批流程

### 组织管理线
```
部门负责人 → 中心总经理（金额超阈值时）
```

### 法人架构线
```
法人财务负责人 → 法人或授权人
```

**审批时效**：
- 每节点须在 3 个工作日内完成审批
- 超时自动升级（HR-005）

## 预算核销流程

1. **审批通过确认**：双线审批均通过
2. **额度扣减**：从预算可用额度中扣减报销金额
3. **核销记录生成**：记录核销金额、时间、关联单据
4. **预算状态更新**：更新预算项目使用金额和执行率
5. **通知反馈**：通知申请人核销完成
