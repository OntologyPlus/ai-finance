# 费用报销规则参考

## 硬规则（Hard Rules）

### HR-001 预算总额控制
- **约束**：报销金额不得超过预算可用额度
- **计算公式**：可用额度 = 冻结额度 - 已使用额度 - 待核销金额
- **违规处理**：系统自动拦截，禁止超预算报销
- **说明**：这是预算管理的底线规则，任何情况下不得突破

### HR-002 强管控科目双线审批
- **约束**：强管控科目须组织线 + 法人线双线审批
- **组织线**：申请人 → 部门负责人 → 中心总经理
- **法人线**：法人财务负责人 → 法人或授权人
- **说明**：先组织管理线，后法人架构线，两条线缺一不可

### HR-005 超时审批自动升级
- **约束**：审批超时未处理时自动升级至上级管理层
- **升级时限**：蓝色 3 天 / 黄色 2 天 / 橙色 1 天 / 红色 立即
- **说明**：防止审批流程成为业务瓶颈

## 软规则（Soft Rules）

### SR-009 费用时效性要求
- **约束**：当年费用须在次年 3 月 31 日前处理完毕
- **违规处理**：逾期原则上不予报销，特殊情况须管委会审批
- **说明**：当年费用次年3月31日后才报销，不予报销，确有特殊原因须管委会特批

### SR-010 预算ID强制挂载
- **约束**：每笔报销必须绑定预算项目ID
- **说明**：无预算ID系统直接拦截，确保数据可追溯

## 四级预算管控模式

不同的费用类别根据集团预算授权模式设置不同的管控方式：

| 管控级别 | 名称 | 控制维度 | 跨部门 | 跨费用类别 | 超预算处理 | L3标签 |
|---------|------|---------|-------|-----------|-----------|--------|
| **强管控** | 强管控费用 | 中心+部门+费用类别+品种组 | ❌ 不可 | ❌ 不可 | 须申请增补预算 | **强管控** |
| **中心弱管控** | 中心弱管控费用 | 中心+费用类别+品种组 | ✅ 中心内可跨 | ❌ 不可跨费用类别 | 部门不足→中心内该费用类别+品种组有余额时，须Finance BP+中心GM审批后使用，无需申请增补 | **中心弱管控** |
| **组合管控** | 中心内组合管控费用 | 中心+品种组 | ✅ 中心内可跨 | ✅ 中心内可跨费用类别 | 部门/费用类别不足→中心内组合包有余额时，须Finance BP+中心GM审批后使用，无需操作预算增补 | **组合管控** |
| **不管控** | 不管控费用 | 无 | ✅ 随意 | ✅ 随意 | 无需预算即可使用 | **不管控** |

> **说明**：管控方式在L3科目上标注，系统根据L3的管控标签自动路由至对应的审批逻辑和校验规则。

## 报销五原则

| 原则 | 说明 |
|------|------|
| **真实** | 报销所依据的事实、金额、数量须与实际业务发生一致，禁止虚构、篡改或伪造报销凭证 |
| **合法** | 报销内容须符合国家法律法规及公司内部制度要求，禁止将违规支出纳入报销范围 |
| **合规** | 报销流程须符合公司既定的审批权限、费用标准及品类管控要求，不得越权审批或超标准报销 |
| **合理** | 报销须与业务实质相关，费用发生具有明确的业务理由和价值贡献，能够回答"这笔钱花得值不值"的问题 |
| **及时** | 当年费用须在次年3月31日前处理完毕，逾期原则上不予报销 |

## 禁止事项

- 禁止无预算ID的费用发生（系统拦截，不允许提交）
- 禁止虚假报销、虚增费用金额
- 禁止粘贴不规范导致单据无法辨识
- 发票原件丢失不补办，特殊情况须特批并处500元罚金

## 违规处理

| 违规场景 | 处理方式 |
|---------|---------|
| 虚假报销/虚增金额 | 退回申请，情节严重者报人力资源部及审计部处理，公司保留追索已付款项的权利 |
| 超预算且未批先报 | 系统拦截，退回补充预算授权后再行提交 |
| 发票不合规（伪造/过期/抬头错误） | 财务BP拒绝接单，报销人须更换合规发票 |
| 发票原件丢失 | 不予报销，特殊情况须特批并处500元罚金 |
| 粘贴不规范导致无法审核 | 退回报销人重新粘贴后再提交 |
| 逾期未报销（超3个月） | 系统限制提交，原则上不予报销 |
| 当年费用次年3月31日后才报销 | 不予报销，确有特殊原因须管委会特批 |

## 大额支出约定

- 大额支出（3万元以上）须提前签订合同
- 差旅/招待等事前申请场景：须在系统提交申请，获得审批后方可发生
- 报销金额按发票金额与实际支出金额**孰低**填写
