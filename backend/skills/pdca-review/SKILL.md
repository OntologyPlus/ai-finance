# PDCA 复盘

## 何时使用此技能
在月度/季度/年度复盘周期，或用户请求 PDCA 复盘、绩效评估、改进计划、周期复盘时使用。触发词包括："PDCA"、"复盘"、"月度复盘"、"季度复盘"、"年度复盘"、"改进计划"、"闭环率"、"plan review"、"performance review"、"improvement plan"。

## 工作流程

本技能采用**流水线模式**：Plan→Do→Check→Act，遵循 PDCA 方法论。

### 步骤1：Plan（计划回顾）
- **为什么**：了解计划内容为后续所有评估提供基准。
- 回顾本期战略目标和预算计划
- 检查计划与实际的对齐度
- 识别计划偏差和原因
- 输出：计划 vs 实际对比表

### 步骤2：Do（执行检查）
- **为什么**：执行数据揭示组织将计划转化为行动的效果。
- 检查预算执行率
- 检查预警闭环率
- 检查关键里程碑完成情况
- 统计各科目执行偏差
- 输出：执行数据汇总表

### 步骤3：Check（检查评估）
- **为什么**：评估将原始数据转化为可操作的洞察，通过分类偏差类型实现。
- 按适当粒度执行评估：
  - **月度**：预警闭环率检查
  - **季度**：战略执行进展评估
  - **年度**：全年执行总结
- 偏差分类：
  - 执行偏差（实际超支是效率问题还是方向问题）
  - 假设偏差（年初假设是否已经过时）
  - 能力偏差（团队是否具备足够资源）
- HR-012：闭环率纳入绩效考核
- 详细评估框架请读取 `references/RULES.md`

### 步骤4：Act（改进行动）
- **为什么**：没有具体改进行动的复盘是不完整的，教训会被遗忘。
- 生成改进计划：
  - 调整下期预算分配
  - 优化管控规则参数
  - 更新战略举措优先级
  - 流程优化和效率提升
- 为每项改进行动分配责任人和完成时限
- 输出：改进措施清单（含责任人和时限）

### 步骤5：输出复盘报告
- **为什么**：结构化报告记录复盘发现并跟踪改进行动。
- 生成输出：
  - 执行摘要
  - 计划 vs 实际对比
  - 偏差分析和根因
  - 改进措施和责任人
  - 下期重点事项

## 输出格式
```
PDCA 复盘报告 [期间：月度/季度/年度]
- 期间：[YYYY-MM 或 YYYY-Qn 或 YYYY]
- 计划 vs 实际：
  - 预算执行率：[N]%（目标：[N]%）
  - 预警闭环率：[N]%（目标：[N]%）
  - 里程碑完成率：[N]%（目标：[N]%）
- 偏差分析：
  - 执行偏差：[N] 项
  - 假设偏差：[N] 项
  - 能力偏差：[N] 项
- 改进措施：
  - [措施1]：[描述、责任人、完成时限、预期影响]
  - [措施2]：...
- 下期重点：[N] 项
```

## 边界情况
- 如果复盘期间无显著偏差，仍生成最小报告确认"正常推进"状态
- 如果上期的改进行动未完成，携带至下期并附升级说明
- 月度复盘输入季度复盘，季度复盘输入年度复盘——确保数据和行动项的连续性

## 方法论参考

| 方法论 | 引用原因 |
|--------|---------|
| CFO交互标准与沟通范式 | 复盘场景需按复盘诊断沟通范式呈现，结论先行，提供3GAP+3List结构化输出，改进行动须带责任人和时间节点 |
| CFO预警响应标准 | PDCA复盘需提取预警闭环档案作为核心输入，预警根因分析纳入改进行动，闭环率纳入绩效考核 |
