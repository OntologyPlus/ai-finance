# PDCA 复盘工作流程

## 1. 业务背景

PDCA复盘是端到端管理体系中"经验沉淀"的核心环节。每一个预算偏差背后，都隐藏着组织改进的机会。复盘的价值不仅在于"找出问题"，更在于把这些问题转化为次年决策的输入，形成年度循环的闭环。

核心管理诉求：如何让复盘成为常态化的改进机制，而非"秋后算账"？月度、季度、年度不同粒度的复盘如何衔接？

## 2. 管理政策

- **复盘不是秋后算账，而是经验沉淀**：偏差分类为执行偏差、假设偏差、能力偏差
- **预警闭环率纳入绩效考核**：未闭环预警须在经营分析会专项汇报
- **PDCA闭环**：分析结论须落地为改进行动，改进行动须纳入次年预算输入
- **一报一会机制**：月度快报+经营管理会，以月度为周期系统扫描执行差距

## 3. 流程设计

### 3.1 月度复盘

**周期**：每月一次，数据定稿后5个工作日内完成

**流程**：

| 步骤 | 操作 | 责任方 |
|------|------|--------|
| 1. 数据汇总核对 | 每月1-12日，各中心帆软数据定稿 | 各中心财经BP |
| 2. 预警闭环率检查 | 统计当月新增/关闭/未闭环预警 | 财经中心 |
| 3. 预算执行率计算 | 按科目/项目/象限统计执行率 | 财经中心预算管理部 |
| 4. 偏差分析 | 超10%科目列示，原因分析 | 财经中心 |
| 5. 改进行动输出 | 明确改进行动、责任人、完成时限 | 各中心财经BP |
| 6. 月度快报发出 | 数据定稿后5个工作日内 | 财经中心 |
| 7. 经营分析会汇报 | 月度快报在经营分析小组内汇报 | 财经中心 |

**时效要求**：

| 节点 | 时效要求 | 责任方 |
|------|---------|--------|
| 实际数系统对接 | 每月5日（总部人力）/8日（区域人力）/10日（全部数据） | 各系统接口 |
| 各中心帆软数据定稿 | 每月12日 | 各中心财经BP |
| 月度快报发出 | 数据定稿后5个工作日内 | 财经中心 |
| 季度汇报材料提交 | 管委会会议前7天 | 财经中心 |

**产出标准**：

| 产出物 | 质量要求 |
|-------|---------|
| 月度快报 | 含执行率/象限执行/预警闭环追踪，数据准确，分析有深度 |
| 偏差分析报告 | 明确列出超10%科目、原因分析、改进行动建议 |
| 预警闭环追踪汇总 | 含当月新增/关闭/未闭环预警清单 |

### 3.2 季度复盘

**周期**：每季度一次，在管委会上进行季度总结陈述

**流程**：

| 步骤 | 操作 | 责任方 |
|------|------|--------|
| 1. 季度数据汇总 | 汇总三个月经营数据 | 财经中心 |
| 2. 3GAP分析 | 目标差距+执行差距+预测变动 | 财经中心 |
| 3. 象限内调拨建议 | 提出同象限内调拨建议 | 财经中心 |
| 4. 滚动预测（Q3/Q4） | 更新全年滚动预测数据 | 各中心财经BP |
| 5. 季度汇报PPT | 含趋势分析、象限调拨建议、滚动预测 | 财经中心 |
| 6. 管委会汇报 | 季度总结陈述 | 财经中心 |

**三中心分工**：

| 中心 | 分析范围 |
|------|---------|
| 财经中心 | 利润表现、收入进度、管理及研发费用中的维持性费用 |
| 运营中心 | 各经营责任中心收入进展、品种表现、新增渠道表现、新产品上市情况、市场推广费用使用情况、销售团队人力情况 |
| 人力中心 | 集团整体人力编制及人力成本使用情况、人力资源管理问题 |

**产出标准**：

| 产出物 | 质量要求 |
|-------|---------|
| 季度汇报PPT | 含趋势分析、象限内调拨建议、三季度/四季度含滚动预测 |
| 滚动预测报告 | 含预测假设、预测偏差分析、下季度预测 |

### 3.3 年度复盘

**周期**：每年一次，次年预算采集前完成

**流程**：

| 步骤 | 操作 | 责任方 |
|------|------|--------|
| 1. 全年数据汇总 | 汇总12个月经营数据和4个季度复盘结果 | 财经中心 |
| 2. 战略执行评估 | 评估三大战略方向执行情况 | 财经中心 |
| 3. PDCA闭环率计算 | 统计全年改进行动闭环情况 | 财经中心 |
| 4. 次年SP/BP调整建议 | 基于年度复盘，提出次年预算组合调整建议 | 财经中心 |
| 5. 年度复盘报告 | 含全年执行总结、改进建议、次年规划 | 财经中心 |
| 6. 管委会审阅 | 审阅年度复盘结论 | 管委会 |

**偏差根因分析框架**：

| 偏差类型 | 可能原因 | 改进行动 |
|---------|---------|---------|
| 执行偏差 | 流程低效、资源错配 | 优化流程、重新分配资源 |
| 假设偏差 | 市场变化、预测不准 | 修正预测模型、更新假设 |
| 能力偏差 | 人员不足、技能不够 | 招聘培训、外部支持 |

**产出标准**：

| 产出物 | 质量要求 |
|-------|---------|
| 年度复盘报告 | 含全年执行总结、PDCA闭环率、改进建议 |
| 次年SP/BP调整建议 | 基于年度复盘，含量化数据支撑 |

## 4. 角色定义

| 角色 | 发起 | 审核 | 批准 | 归档 |
|------|------|------|------|------|
| **各中心财经BP** | ✅ 本中心数据填报 | ✅ 本中心数据复核 | ✅ 本中心确认放行 | ✅ 本中心分析报告存档 |
| **预算管理部** | ✅ 集团汇总分析 | ✅ 集团数据总分复核 | ✅ 集团报告审核 | ✅ 集团报告存档 |
| **财经中心** | — | ✅ 整体审核 | ✅ 报送管委会 | — |
| **运营中心** | — | ✅ 收入/品种/推广费分析 | ✅ 中心报告审核 | — |
| **人力中心** | — | ✅ 人力成本分析 | ✅ 中心报告审核 | — |
| **管委会** | — | — | ✅ 季度/年度汇报审阅+决策 | — |

## 5. 违规处理

| 违规场景 | 处理方式 |
|---------|---------|
| 虚假瞒报经营数据 | 退回数据，情节严重者上报管委会及审计部 |
| 未经授权调整已定稿数据 | 数据无效，恢复至最近一次授权版本，责任人记过 |
| 数据不按统一利润表格式填报 | 退回重填，影响汇总进度者通报批评 |
| 逾期未提交预警闭环档案 | 系统限制新增 |
| 未按要求在经营分析会汇报预警闭环情况 | 财经中心记录并在下次管委会专项汇报，责任人纳入绩效考核 |
