# 成本中心核算

## 何时使用此技能
在成本中心核算期间、需要设置标准成本、进行差异分析、执行费用分摊、处理内部结算，或用户询问"成本中心"、"标准成本"、"差异分析"、"费用分摊"、"内部结算"、"转移价格"时使用。

## 工作流程

本技能采用**并行模式**：标准成本设定、差异分析、成本分摊、内部结算可独立执行，但差异分析依赖标准成本设定。

### 步骤1：标准成本设定
- **为什么**：标准成本是衡量实际成本合理性的基准，没有标准就无法判断偏差。
- 为每个成本中心设定各成本项目的标准用量和标准单价
- 系统自动计算标准成本总额 = 标准用量 × 标准单价
- 支持更新已有标准成本（生效日期自动更新）

### 步骤2：差异分析
- **为什么**：差异分析揭示成本控制的薄弱环节，指导管理改进。
- 价格差异 = (实际单价 - 标准单价) × 实际用量
- 数量差异 = (实际用量 - 标准用量) × 标准单价
- 总差异 = 价格差异 + 数量差异
- 差异评估：正常(≤5%) / 轻微偏差(5-10%) / 显著偏差(10-20%) / 严重偏差(>20%)

### 步骤3：成本分摊
- **为什么**：公共费用需要按合理基准分摊到各责任中心。
- 支持按人数、面积、收入比例等基准分摊
- 分摊比例之和必须等于1.0
- 分摊结果可追溯

### 步骤4：内部结算
- **为什么**：内部服务需要通过转移价格机制进行结算，确保各中心成本真实。
- 提供方和使用方不能为同一成本中心
- 结算金额 = 服务量 × 内部转移价格
- 结算状态：待结算→已结算/已驳回

## 输出格式
```
成本中心核算报告 [期间]
- 成本中心：[N] 个
- 标准成本项目：[N] 个
- 差异分析：
  - 总标准成本：[N] 万元
  - 总实际成本：[N] 万元
  - 总差异：[N] 万元（[N]%）
  - 价格差异：[N] 万元
  - 数量差异：[N] 万元
- 分摊执行：[N] 笔
- 内部结算：[N] 笔
```

## 边界情况
- 如果成本中心未设置标准成本，差异分析将返回错误提示
- 分摊比例之和不为1.0时拒绝执行分摊
- 内部结算的提供方和使用方不能为同一中心
