# 管线生命周期与项目制预算

## 何时使用此技能
在管线阶段推进/终止决策、R&D项目预算管理、CRO付款追踪、多中心临床试验分摊、R&D效率分析，或用户询问"管线推进"、"Go/No-Go"、"R&D预算"、"双口径"、"CRO付款"、"多中心分摊"、"研发效率"时使用。

## 工作流程

本技能采用**双轨模式**：管线生命周期管理和R&D项目制预算管理并行运行，通过管线-项目关联实现联动。

### 管线生命周期管理轨道

#### 步骤1：管线推进（HR-030）
- **为什么**：管线阶段推进是R&D最重要的决策节点，必须经过Go/No-Go评估。
- 管线阶段：发现→临床前→I期临床→II期临床→III期临床→注册申报→上市
- 推进必须明确Go/No-Go决策
- Go决策：推进到目标阶段
- No-Go决策：进入终止评估流程（HR-031）

#### 步骤2：管线终止/暂停
- **为什么**：及时终止无前景管线可释放资源，避免沉没成本继续扩大。
- 终止（HR-032）：释放剩余预算，终止关联项目
- 暂停（HR-033）：冻结预算但保留，关联项目暂停

#### 步骤3：管线状态查询
- 查看管线当前阶段、预算消耗、关联项目和临床试验
- 计算阶段进度百分比

### R&D项目制预算管理轨道

#### 步骤4：双口径预算（财务口径/管理口径）
- **为什么**：财务口径满足会计准则，管理口径满足项目管控需要，两者必须分开管理。
- 财务口径：按照会计准则确认的研发支出（费用化部分）
- 管理口径：按照项目管理需要归集的全部研发投入（费用化+资本化）
- 管理口径预算应≥财务口径预算

#### 步骤5：CRO付款追踪
- **为什么**：CRO费用是R&D最大支出项，必须关联里程碑进行追踪。
- CRO付款关联里程碑
- 付款后自动更新项目消耗（双口径同步更新）
- 里程碑状态自动更新

#### 步骤6：多中心分摊
- **为什么**：多中心临床试验费用需按协议分摊到各中心。
- 根据分摊协议比例计算各中心分摊金额
- 比例之和必须等于1.0

#### 步骤7：R&D效率分析
- **为什么**：持续监控R&D效率是优化研发投入的关键。
- 预算执行率（双口径）
- 里程碑完成率/延期率
- 管线推进效率
- CRO费用占比

## 输出格式
```
R&D效率报告 [期间]
- 活跃管线：[N] 条
- 活跃项目：[N] 个
- 财务口径执行率：[N]%
- 管理口径执行率：[N]%
- 口径差异：[N] 万元
- 里程碑完成率：[N]%
- 效率评估：[偏低/正常/较高/超预算]
```

## 边界情况
- No-Go决策不直接终止管线，而是进入终止评估流程
- 管线终止时自动终止关联的进行中项目
- 管线暂停时冻结预算但保留，可恢复
- CRO付款超过剩余预算时拒绝执行
- 管理口径预算不得小于财务口径预算

## 方法论参考

| 方法论 | 引用原因 |
|--------|---------|
| CFO指标定义与数据口径标准 | 管线管理需使用标准研发效能指标口径（管线NPV、研发投入资本化率、临床推进速度），双口径预算需与标准执行率口径一致 |
| CFO预警响应标准 | 管线里程碑延期和预算超支需按预警分级标准触发预警，Go/No-Go决策需按响应时效及时处理 |
