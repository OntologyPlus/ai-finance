# 预算编制

## 何时使用此技能
在年度预算编制期间、战略目标（SP/BP）需要重新编制预算、或用户询问预算编制、战略对齐、A/B 分类、象限归属、预算框架、"预算编制"、"战略对齐"、"A类B类"、"四象限"时使用。设置预算模板或将战略举措解码为预算项目时也会触发。

## 工作流程

本技能采用**流水线模式**：理解战略→编制预算项目→象限归属→规则校验，各步骤有明确的顺序依赖。

### 步骤1：理解战略目标
- **为什么**：预算不是财务行为而是战略行为——没有清晰的战略方向，预算只是数字游戏。
- 获取当前 SP（战略规划）和 BP（年度业务计划）目标
- 识别关键战略举措
- 根据三大战略方向确定预算范围和优先级：
  - 全渠道商业化（优先级：资源优先保障，与收入增长联动）
  - 创新研发（优先级：长期布局，阶段性评审）
  - 国际化（优先级：战略卡位，优先投入已准入市场）
- 详细工作流程请读取 `references/WORKFLOW.md`

### 步骤2：编制预算项目
- **为什么**：每个战略举措必须转化为具体、可追踪的预算项目。
- 为每个战略举措创建预算项目：
  - 分配 A/B 分类：
    - **A类（战略专项）**：目标明确、计划确定 → 全额授予，额度锁定
    - **B类（前置探索）**：结果不确定、需验证效果 → 授予 50-70%，里程碑验证后分批释放
  - 分配 L1/L2/L3 科目归属
  - 计算年度预算额度
  - 关联战略意图维度（战略方向 × 产品线/区域）

### 步骤3：象限归属
- **为什么**：象限归属决定管理策略和资源配置优先级。
- 根据战略对齐度和 ROI 预期确定象限：
  - **发展象限**：战略优先级高、ROI 预期好 → 加大投入，优先保障
  - **收缩象限**：战略优先级低、ROI 预期差 → 压降预算，逐步退出
  - **稳定象限**：战略优先级中、ROI 稳定 → 精准投入，维持现状
  - **探索象限**：战略优先级高、ROI 不确定 → 有限投入，验证效果

### 步骤4：规则校验
- **为什么**：防止违反核心约束的预算计划进入系统。
- HR-001：预算总额不得超过 SP/BP 战略目标总额
- HR-007：A类预算必须冻结对应额度
- HR-008：跨象限调拨须管委会批准
- SR-007：B→A 转换需里程碑达标证据
- 详细规则定义请读取 `references/RULES.md`

### 步骤5：输出编制结果
- **为什么**：提供清晰、可执行的预算计划供审查和批准。
- 生成输出：
  - 预算项目清单（含 A/B 分类和象限归属）
  - 科目汇总表（按 L1/L2/L3）
  - 战略对齐度分析
  - 审批流程详情请读取 `references/WORKFLOW.md`

## 输出格式
```
预算编制报告 [年度]
- 预算总额：[N] 万元（SP/BP 限额：[N] 万元）
- 预算项目：[N] 个
  - A类：[N] 个，[N] 万元（[N]%）
  - B类：[N] 个，[N] 万元（[N]%）
- 象限分布：
  - 发展象限：[N] 个，[N] 万元
  - 收缩象限：[N] 个，[N] 万元
  - 稳定象限：[N] 个，[N] 万元
  - 探索象限：[N] 个，[N] 万元
- 规则校验：[全部通过 / 发现 N 项违规]
```

## 边界情况
- 如果战略举措无法明确分类为 A 或 B，默认归为 B类（前置探索）并降低初始授予比例
- 如果总规划预算超过 SP/BP 限额，标记项目进行 PK/谈判——不要自动削减
- B类授予比例每项不得超过年度额度的 30%（HR-004）
