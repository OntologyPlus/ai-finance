# 预算编制工作流程

## 战略解码流程（管委会 + 财经中心）

1. 管委会基于集团 SP 确定年度战略方向
2. 明确三大战略方向的资源配置权重
3. 财经中心将战略方向解码为战略举措
4. 形成可执行的项目清单

## 框架下达流程

1. 财经中心编制年度预算工作时间表
2. 下发统一预算模板
3. 管委会下达年度预算框架
   - 资源配置权重
   - 关键财务指标目标

## 自下而上申报流程

1. 各中心根据战略方向提交年度预算申请
2. 结合本中心业务实际编制
3. 各中心财经 BP 在系统中录入预算数据
4. 确保口径一致

## 汇总 PK 与平衡流程

1. 财经中心对各中心预算申请进行汇总
2. 与战略意图进行比对
3. 对存在偏差的预算进行 PK、谈判、调整
4. 可能经历多轮上下往返，直至各方达成一致

## 终审与锁定流程

1. 管委会终审年度预算
2. 批准年度预算总额及各中心预算框架
3. 终审锁定的对象是**年度预算总额及各中心框架**，不是分类额度
4. A/B 分类授予在阶段二（预算授予）完成
5. 财经中心将已批准的年度预算总额记入系统

## 年度预算审批流程

| 步骤 | 审批人 | 说明 |
|------|--------|------|
| 1 | 预算申请人 | 发起预算申报，提交至系统 |
| 2 | 预算申请部门负责人 | 审核本部门预算申报的真实性与合理性 |
| 3 | 判断：是否为院外到经营中心预算？ | 是→步骤4；否→步骤5 |
| 4 | 院外渠道中心总经理 | 院外专项审批 |
| 5 | 财务BP/预算专员 | 审核预算口径一致性与合规性 |
| 6 | 责任中心财务负责人 | 审核责任中心预算数据的完整性 |
| 7 | 经营责任中心总经理 | 审核本中心预算分配的合理性 |
| 8 | 矩阵授权审批人(MA) | 按矩阵管理关系审批，授予分类额度 |
| 9 | 审批通过 | 最终审批完成 |
