# CFO 一把手视图（Executive Dashboard）

## 何时使用此技能

当 CFO / 财务总监查询以下内容时使用此技能：
- 整体预算执行率、闭环率、超期预警数
- 仪表盘视图 / 一把手视图 / 看板
- 聚合指标汇总
- TOP-N 关注清单（哪些项目需要我关注）
- 趋势分析（环比 / 同比 / 连续趋势）
- 象限健康度评分
- 现金流偏差
- 人效指标

触发词包括："执行率"、"红灯数"、"闭环率"、"象限健康度"、"一把手视图"、"看板"、"哪些需要关注"、"趋势"、"现金流"、"人效"、"dashboard"、"overview"。

## 核心能力

### 1. 全局指标聚合

- **执行率** = Σ已核销 / Σ年度预算 × 100%
- **闭环率** = 已闭环预警 / 总预警 × 100%
- **超期预警数** = 响应截止日期已过且未闭环的预警条数

### 2. 四象限健康度评分

按发展/收缩/稳定/探索四个象限分别计算执行率，采用5色灯色判定：

| 灯色 | 含义 | 判定规则 |
|------|------|---------|
| 🟢 绿色 | 健康 | 执行率在目标范围内 |
| 🔵 蓝色 | 正常 | 执行率轻微偏离目标，偏差≤5% |
| 🟡 黄色 | 关注 | 执行率偏离目标5%-15% |
| 🟠 橙色 | 预警 | 执行率偏离目标15%-25% |
| 🔴 红色 | 严重 | 执行率偏离目标>25% 或触发红色预警 |

### 3. TOP-N 关注清单

按优先级排序生成关注清单，排序规则：
1. 🔴 红色预警项
2. 🟠 橙色预警项
3. 超期未闭环项
4. 偏离最大象限项
5. B类里程碑延期项

### 4. 趋势对比逻辑

华为管理强调"趋势比绝对值更重要"，自动呈现趋势对比：

- **环比变化**：本月 vs 上月，标注变化方向（↑↓→）和变化幅度
- **同比变化**：本月 vs 去年同期，标注变化方向和幅度
- **趋势判断**：连续3个月同方向变化 → 标注趋势（持续改善/持续恶化/波动）
- **异常检测**：单月变化>10% → 标注"异常波动"，需说明原因

### 5. 现金流双线监控

华为财经管理核心是"利润+现金流双轮驱动"：

- **现金执行率** = 实际现金支出 / 预算现金支出 × 100%
- **现金流偏差** = 预算执行率 - 现金执行率
  - 偏差≤5%：正常
  - 偏差5%-10%：关注（可能存在应付账款积压或预付款过多）
  - 偏差>10%：预警（需核实数据质量）

### 6. 人效指标

华为强调"人效是核心经营指标"：

- **人均预算执行额** = 已核销金额 / 部门人数
- **人均创收** = 部门收入 / 部门人数
- **人效趋势**：人均指标环比/同比变化

### 7. 一报一会范式

一把手视图服务于月度经营分析会，是华为"一报一会"机制中"一报"（经营分析报告）的核心输出。经营分析会是作战会议，不是汇报会，必须聚焦三件事：
1. **聚焦目标**：对照年度目标谈结果、谈差距、谈行动
2. **聚焦问题**：发现差距、找出根因、制定行动方案
3. **聚焦机会**：列出未来机会清单，对准机会谈策略行动与资源

## 工作流程

**分层聚合**：先汇总→再明细，先全局→再下钻。

1. **判断查询层级**：识别用户意图属于全局概览、象限下钻还是单项目关注
2. **聚合核心指标**：执行率、闭环率、灯色分布、超期预警
3. **生成 TOP-N 关注清单**：按优先级排序输出关注项
4. **趋势对比分析**：环比/同比/连续趋势/异常波动检测
5. **输出结构化仪表盘视图**：按华为汇报范式组织输出

【象限健康度】  发展[XX]%  收缩[XX]%  稳定[XX]%  探索[XX]%

## 边界情况

| 边界情况 | 处理方式 |
|---------|---------|
| 无预警 | "本月预警情况正常，无红色/橙色预警" |
| 预算项为空 | "当前无进行中的预算项目"，建议确认预算编制流程是否已启动 |
| 闭环率 <80% | 操作建议中提醒"建议加强预警响应机制" |
| 执行率 >100% | 标注"超预算执行"，需核实是否有调增审批或数据异常 |
| 无当月数据 | 提示"当前月份暂无数据"，展示最近有数据月份的视图 |
