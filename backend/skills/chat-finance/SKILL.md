# 财经对话

## 何时使用此技能
用于任何财经相关的对话，从简单的事实查询到复杂的战略分析。触发词包括预算、费用、预警、报表、审批、财务分析、"财经"、"预算"、"费用"、"预警"、"报表"、"审批"、"报销"、"分析"。这是财经领域通用对话的默认技能。

## 能力等级

本技能采用**工具选择模式**：根据查询复杂度和上下文选择合适的回复层级。

### L1 事实查询
- **适用场景**：用户询问具体数据点或状态
- **能力**：回答预算、费用、预警等事实性问题
- **数据源**：系统实时数据
- **示例**："B1科目当前预算是多少？"、"本月执行率是多少？"、"当前有哪些红色预警？"
- **回复风格**：直接、精确，附数据来源引用

### L2 逻辑推理
- **适用场景**：用户的问题需要基于规则进行推理
- **能力**：基于硬规则（HR-xxx）和软规则（SR-xxx）进行推理判断
- **示例**："这个报销金额会触发预警吗？"、"这笔费用需要双线审批吗？"
- **回复风格**：解释推理链，引用适用规则

### L3 方案推荐
- **适用场景**：用户请求建议或方案
- **能力**：根据分析结果推荐行动方案
- **示例**："预算执行率偏低，有什么建议？"、"B2科目预计超预算怎么办？"
- **回复风格**：提供选项，附理由和预期效果

### L4 方案模拟
- **适用场景**：用户提出"如果...会怎样"的问题
- **能力**：模拟不同场景的执行效果
- **示例**："如果调拨50万到B5科目会怎样？"
- **回复风格**：展示调整前后对比，突出风险

### L5 报告生成
- **适用场景**：用户请求结构化报告
- **能力**：生成月度快报、季度分析、年度复盘
- **示例**："帮我生成本月执行快报"
- **回复风格**：如需详细报告则委托给 `report-generation` 技能

### L6 主动建议
- **适用场景**：上下文揭示潜在风险，用户未明确要求
- **能力**：主动识别风险并提供建议
- **示例**："注意：B2科目执行率已达85%，预计Q3将超预算"
- **回复风格**：简洁的风险预警，附建议行动

## 回答规范

1. **基于事实和规则**：不编造数据，所有回答须有数据来源或规则依据
2. **引用规则标注编号**：引用规则时标注规则编号（如"根据 HR-001..."）
3. **金额使用精确数值**：涉及金额时使用精确数值，不估算
4. **推荐方案给出理由**：推荐方案时给出理由和预期效果
5. **主动识别风险**：基于上下文主动识别潜在风险并提醒用户
6. **不确定性说明**：对不确定的回答明确标注"需要进一步确认"

## 回复策略选择

| 查询复杂度 | 回复层级 | 操作 |
|-----------|---------|------|
| 简单数据查询 | L1 | 直接返回数据 |
| 基于规则的问题 | L2 | 推理并引用规则 |
| 建议请求 | L3 | 推荐并附选项 |
| 假设场景 | L4 | 模拟并对比 |
| 报告请求 | L5 | 生成或委托 |
| 上下文检测到风险 | L6 | 主动预警 |

详细能力等级定义和回复规范请读取 `references/RULES.md`。
